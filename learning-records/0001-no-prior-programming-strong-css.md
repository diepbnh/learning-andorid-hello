# Chưa có nền tảng lập trình logic, nhưng mental model CSS mạnh

Người học xác nhận: giỏi HTML/CSS, nhưng **chưa từng viết code logic** (biến, hàm, điều kiện, vòng lặp) ở bất kỳ ngôn ngữ lập trình nào — kể cả JavaScript. Điều này đặt điểm bắt đầu của khóa học ở mức thấp hơn "designer biết code" thông thường: các lesson đầu không thể giả định người học hiểu `val`, hàm, hay `if/else` mà phải giới thiệu chúng lần đầu, xen kẽ với khái niệm Compose.

Ngược lại, mental model CSS (box model, cascade, class/style) là nền tốt để so sánh với Modifier chain và theming của Compose — nên tận dụng triệt để phép so sánh này thay vì dạy Kotlin/Compose "trần" như với một lập trình viên đã biết ngôn ngữ khác.

**Implications**: Lesson 1 nên ưu tiên đọc-hiểu + chạy/sửa code có sẵn (tạo tangible win nhanh, đúng Goal 1 trong [[MISSION.md]]) hơn là bắt viết logic từ đầu. Khái niệm biến/hàm nên được giới thiệu tối thiểu, đúng lúc cần, không dạy riêng một lesson "Kotlin cơ bản" tách biệt khỏi UI.
