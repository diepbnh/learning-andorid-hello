Lộ trình UI: mọi thứ HTML có, Compose làm thế nào

Mỗi dòng là một thành phần UI quen thuộc trên web và tên tương đương trong Compose. Cột "Bài" cho biết thành phần đó được học ở bài nào. ✓ là đã xong. Thứ tự đi từ gần CSS nhất tới cần nhiều kiến thức nhất.
