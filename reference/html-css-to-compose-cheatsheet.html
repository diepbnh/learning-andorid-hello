HTML/CSS ⇄ Jetpack Compose

Bảng đối chiếu để tra cứu nhanh khi đọc code Compose. Không cần học thuộc — quay lại đây mỗi khi quên. Sinh ra từ Bài 1 · Đọc hiểu Composable đầu tiên.

Cấu trúc & Component

HTML/CSSCompose/KotlinGhi chú
<div class="card">...</div>
hoặc một React/Vue component		 @Composable fun Card(...) { ... } Một hàm được đánh dấu @Composable = một "custom element" tái sử dụng được, giống component web.
Gọi component: <Card /> Gọi composable: Card() Gọi một composable = viết tên hàm như một câu lệnh, không cần return.
props <Button color="blue" /> tham số hàm: fun AppButton(text: String, backgroundColor: Color) Tham số composable = props. Có thể có giá trị mặc định, giống defaultProps.

Cú pháp Kotlin tối thiểu cần biết

KotlinÝ nghĩa
val name = "..."Khai báo giá trị không đổi (giống const).
var name = "..."Khai báo giá trị có thể đổi (giống let).
fun ten(a: Int): String { ... }Khai báo hàm: tên, tham số có kiểu, kiểu trả về.
{ ... } ở cuối lời gọi hàmTrailing lambda — một hàm "con" truyền vào, ví dụ nội dung bên trong Column { }.
x = if (a) B else Cif cho ra một giá trị, giống Boolean property trong Figma chọn giữa 2 kết quả. Bắt buộc có else.
fun F(label: String, isPassword: Boolean = false)Tham số có = ... là tùy chọn. Tham số không có mặc định là bắt buộc (ví dụ value).

Variant (nhiều lựa chọn style cố định)

Thiết kế / CSSKotlin/ComposeGhi chú
Property "Variant" trong Figma (Primary/Danger/...), hoặc class btn-primary, btn-danger enum class AppButtonColor { Primary, Danger, Light } Một danh sách cố định, đóng các lựa chọn hợp lệ — không thể truyền giá trị ngoài danh sách này, khác với truyền tự do một Color.
Chọn style theo class/variant (nhiều if/else if, hoặc map trong design tool) when (variant) { Primary -> ...; Danger -> ... } when giống if/else if nhưng rõ ràng hơn khi có nhiều nhánh — và Kotlin sẽ báo lỗi nếu bạn quên xử lý một case.

Xem ví dụ áp dụng ở Bài 2 · Component Variant.

Không nhầm với bảng màu theme. AppColors (trong Color.kt) là dữ liệu — màu thật sự đằng sau mỗi token, đổi theo light/dark. AppButtonColor (enum) là ràng buộc API — danh sách những gì riêng AppButton được phép nhận, không phải mọi token trong theme đều hợp lý làm màu nền nút (ví dụ colors.text thì không). Hai lớp khác nhau, không thay thế nhau — giống panel "Color styles" so với property "Variant" của component trong Figma.
