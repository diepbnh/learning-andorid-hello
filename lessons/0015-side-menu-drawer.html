Menu trượt bên trái: nút hamburger ☰ và ModalNavigationDrawer, giống ion-menu

Bài 14: xong. AppTopBar của bạn dùng 2 slot navigationIcon và actions thay cho tham số onBack của bài. Chính nhờ thiết kế đó mà bài này đặt được nút hamburger vào header mà không phải sửa AppTopBar.

Kết quả mong đợi

Trang Menu có nút ☰ ở góc trái header. Bấm vào thì menu trượt ra từ bên trái, có phần đầu (avatar, tên) và danh sách các trang. Mục của trang hiện tại được tô nền. Vùng còn lại phủ nền tối, bấm vào đó thì menu đóng. Hình bấm được.

Chú ý khi so sánh: menu rộng khoảng 280dp, che lên trên cả header, nền colors.backgroundCard, bo 2 góc bên phải. Nền tối phía sau dùng token colors.backgroundDialog của bạn. Mục đang chọn có nền colors.primary mờ 15% và chữ/icon colors.primary. Các mục còn lại chữ colors.text. Chọn một mục thì menu đóng lại rồi chuyển trang.

1. Cấu trúc: menu bọc ngoài trang

Ionic 
<ion-menu contentId="main">
  <ion-content>
    <ion-list> ...các mục... </ion-list>
  </ion-content>
</ion-menu>

<div id="main">
  <ion-header><ion-toolbar>
    <ion-menu-button></ion-menu-button>
  </ion-toolbar></ion-header>
  ...
</div>
Compose 
ModalNavigationDrawer(
    drawerState = drawerState,
    drawerContent = {          // ion-menu
        ModalDrawerSheet {
            // ...các mục...
        }
    }
) {                            // #main
    AppPage(
        topBar = {
            AppTopBar(navigationIcon = {
                // nút ☰ (ion-menu-button)
            })
        }
    ) { ... }
}

ModalNavigationDrawer có 2 phần: drawerContent là cái menu (lúc đầu ẩn bên trái), còn phần trong { } cuối là trang bình thường. Vì menu bọc ngoài AppPage, nên khi mở nó che được cả header. ModalDrawerSheet là "tấm" menu có sẵn nền, bo góc và chiều rộng chuẩn, giống ion-content bên trong ion-menu.

2. Mở menu: drawerState và scope.launch

Ionic (JS) 
async openMenu() {
  await this.menuCtrl.open();
}
Compose 
val drawerState = rememberDrawerState(DrawerValue.Closed)
val scope = rememberCoroutineScope()

IconButton(onClick = {
    scope.launch { drawerState.open() }
}) {
    Icon(Icons.Default.Menu, contentDescription = "Mở menu")
}
  • drawerState là State của menu (đang mở hay đóng), giống isOpen bạn dùng cho Dialog. Khác ở chỗ bạn không tự gán true/false, mà gọi open() / close().
  • open() chạy một animation trượt, cần thời gian mới xong. Giống menuCtrl.open() của Ionic trả về Promise và phải await. Trong Kotlin, việc "tốn thời gian" phải chạy trong scope.launch { ... }.
  • rememberCoroutineScope() tạo ra scope đó, gắn với trang: rời trang thì việc đang chạy tự dừng. Bạn chỉ cần nhớ công thức: muốn gọi open() / close() trong onClick thì bọc bằng scope.launch { }.

Bấm vào nền tối, bấm nút Back của điện thoại, hoặc vuốt menu sang trái đều đóng menu. Bạn không cần viết thêm gì cho các thao tác này.

3. Danh sách mục: data class + forEach

Ở Bài 6 bạn đã dùng data class cho các hàng của bảng. Mỗi mục menu cũng có 3 thông tin giống nhau: chữ, route và icon.

data class MenuItem(
    val label: String,       // chữ hiển thị
    val route: String,       // route để navigate
    val icon: ImageVector,   // icon, ví dụ Icons.Default.Person
)

val menuItems = listOf(
    MenuItem("Profile", "profile", Icons.Default.Person),
    MenuItem("Setting", "checkbox", Icons.Default.Settings),
    // ...
)

Giống một mảng object trong JS: [{ label: 'Profile', route: 'profile', icon: ... }, ...]. ImageVector là kiểu của các icon Icons.Default....

5. Nhiệm vụ

Bước 1: trang mới. Tạo MenuPage.kt, route "menu", link từ TemplatePage. Trang dùng AppPage + AppTopBar(title = "Menu"), trong navigationIcon đặt nút ☰ (Icons.Default.Menu). Chưa cần làm gì khi bấm.

Bước 2: bọc ModalNavigationDrawer quanh AppPage. Khai báo drawerState và scope ở đầu hàm. Cho nút ☰ mở menu như mục 2. Tạm thời để drawerContent = { ModalDrawerSheet { Text("Menu") } }. Build, chạy, bấm ☰ và thử vuốt từ mép trái.

Bước 3: danh sách mục. Code mẫu cho phần drawerContent (đã build thử, chạy được):

drawerContent = {
    ModalDrawerSheet(
        drawerContainerColor = colors.backgroundCard,
        modifier = Modifier.width(280.dp)
    ) {
        // phần đầu menu: tự làm ở Bước 4

        menuItems.forEach { item ->
            NavigationDrawerItem(
                label = { Text(item.label) },
                icon = { Icon(item.icon, contentDescription = null) },
                selected = item.route == "menu", // trang hiện tại
                onClick = {
                    scope.launch { drawerState.close() } // đóng menu
                    navController.navigate(item.route)   // chuyển trang
                },
                colors = NavigationDrawerItemDefaults.colors(
                    selectedContainerColor = colors.primary.copy(alpha = 0.15f),
                    selectedTextColor = colors.primary,
                    selectedIconColor = colors.primary,
                    unselectedTextColor = colors.text,
                    unselectedIconColor = colors.text,
                ),
                modifier = Modifier.padding(horizontal = 12.dp)
            )
        }
    }
}

Tạo data class MenuItem (ở cuối file MenuPage.kt là được) và danh sách 5 mục: Menu, Profile, Card, Setting (route "checkbox"), Template. Icon gợi ý: Icons.Default.Menu, Person, Star, Settings, Home. Import launch từ kotlinx.coroutines.launch.

Bước 4: phần đầu menu và nền tối. Tự làm phần đầu theo hình kết quả: một Row có AppAvatar nhỏ (40dp), tên và chức danh, padding 24dp, bên dưới là một đường kẻ mảnh. Đường kẻ dùng HorizontalDivider(color = colors.light), giống <hr> (học kỹ ở Bài 18). Thêm scrimColor = colors.backgroundDialog vào ModalNavigationDrawer để nền tối đồng bộ với Dialog.

Bước 5: kiểm tra. Mở bằng nút ☰ và bằng cách vuốt. Đóng bằng nền tối, nút Back điện thoại và vuốt sang trái. Chọn một mục thì menu đóng và chuyển trang. Kiểm tra Light/Dark.

Thử thách: tách thành component AppDrawer trong ui/components/layout/ để trang nào cũng có menu. Component cần nhận navController, drawerState, currentRoute (để tô đúng mục) và slot content cho phần trang. Danh sách menuItems đặt bên trong component, vì cả app dùng chung một menu. Hãy hỏi agent khi bạn muốn làm. Lưu ý: mỗi lần navigate là chồng thêm một trang vào lịch sử, nên bấm Back nhiều lần sẽ đi qua lại các trang đã mở. Cách xử lý sẽ học cùng thanh menu dưới. Báo "xong bài 15" khi xong.
