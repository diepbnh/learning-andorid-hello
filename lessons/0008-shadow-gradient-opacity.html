Shadow, Gradient, Opacity: box-shadow, linear-gradient, opacity

Bài 7: xong. AppAvatar có API tốt và đặt shadow trước clip đúng thứ tự. Bạn còn tự làm thêm chữ in đậm một phần (buildAnnotatedString) và con bướm bay (animation). Ảnh cũng đã được giảm kích thước, nên app nhẹ hơn nhiều.

Còn 1 việc dọn dẹp (nên làm trước bài này): ProfilePage vẫn dùng Icons.Default.Home/Favorite/Person, và app/build.gradle.kts vẫn còn 2 dòng material.icons.core và material.icons.extended. Thư viện extended rất nặng, đây là lý do build chậm. Cách sửa: tải 3 icon XML như mục 1 của Bài 7, đổi sang Icon(painter = painterResource(R.drawable.ic_home), ...), xoá 3 dòng import ...icons..., rồi xoá 2 dòng thư viện trong build.gradle.kts. Bấm Sync rồi build lại.

Kết quả mong đợi

Một trang Effect có 4 khối: banner gradient, card có bóng đổ, ảnh có lớp phủ tối để chữ dễ đọc, và 2 hàng so sánh opacity với rgba.

Chú ý khi so sánh: banner chuyển màu từ colors.primary (trái) sang colors.secondary (phải). Card có bóng đổ rõ ở Light Mode. Ở Dark Mode bóng gần như không thấy, nên card được phân biệt nhờ nền sáng hơn nền trang. Chữ trên ảnh luôn đọc được vì nửa dưới ảnh tối dần. Ở hàng alpha, chữ mờ theo ô. Ở hàng copy(alpha), chỉ nền mờ, chữ vẫn rõ.

1. linear-gradient → Brush

CSS 
.banner {
  background: linear-gradient(
    to right,
    var(--primary),
    var(--secondary));
  border-radius: 12px;
}
Compose 
Modifier.background(
  brush = Brush.horizontalGradient(
    listOf(colors.primary, colors.secondary)
  ),
  shape = RoundedCornerShape(12.dp)
)

Brush là "cây cọ" để tô nền: thay vì tô một màu (Color) thì tô một dải màu. listOf(...) là danh sách các màu, giống danh sách color stop trong CSS, và bạn có thể đưa vào 3–4 màu.

CSSCompose
linear-gradient(to right, …)Brush.horizontalGradient(…)
linear-gradient(to bottom, …)Brush.verticalGradient(…)
linear-gradient(135deg, …) (chéo)Brush.linearGradient(…), mặc định đi từ góc trên trái xuống góc dưới phải
radial-gradient(…)Brush.radialGradient(…)

Truyền shape vào background thì nền được bo góc ngay, không cần clip. Dùng màu theme thì gradient tự đổi theo Light/Dark.

2. box-shadow → Modifier.shadow

CSS 
.card {
  box-shadow: 0 4px 10px
    rgba(0,0,0,.18);
  border-radius: 16px;
  background: white;
  padding: 16px;
}
Compose 
Modifier
  .shadow(
    elevation = 8.dp,
    shape = RoundedCornerShape(16.dp)
  )
  .background(colors.surface,
    RoundedCornerShape(16.dp))
  .padding(16.dp)

Compose không cho chỉnh từng thông số x / y / blur / spread như CSS. Bạn chỉ chọn elevation, tức là "card nổi cao bao nhiêu", và Android tự vẽ bóng. Số càng lớn thì bóng càng to và mềm. Thường dùng 1–2dp cho card nhẹ, 6–8dp cho card nổi bật, 16dp cho popup.

Thứ tự quan trọng, giống AppAvatar của bạn: shadow phải đứng trước background. Modifier được áp dụng từ trên xuống: vẽ bóng trước, rồi tô nền lên trên, rồi mới thụt padding vào trong. Nếu đặt padding lên đầu thì bóng và nền sẽ nhỏ lại, giống như bạn đặt margin thay vì padding trong CSS.

Dark Mode: bóng màu đen không thấy được trên nền tối. Vì vậy Material Design dùng nền card sáng hơn nền trang để thể hiện độ nổi. Đó là lý do bài này cần thêm một màu mới: surface (màu nền card), ở Bước 2.

3. Chữ trên ảnh: lớp phủ gradient bằng Box

CSS 
.hero { position: relative; }
.hero::after {
  position: absolute; inset: 0;
  background: linear-gradient(
    to bottom, transparent,
    rgba(0,0,0,.7));
}
.hero span {
  position: absolute;
  left: 12px; bottom: 12px;
}
Compose 
Box(Modifier...clip(...)) {
  Image(...)       // lớp dưới cùng
  Box(             // lớp phủ
    Modifier.fillMaxSize()
      .background(Brush.verticalGradient(
        listOf(Color.Transparent,
          Color.Black.copy(alpha = 0.7f))))
  )
  Text(..., Modifier          // lớp trên cùng
    .align(Alignment.BottomStart))
}

Box là position: relative: các con bên trong chồng lên nhau, con viết sau nằm trên con viết trước (giống z-index tăng dần theo thứ tự). Modifier.align(...) chỉ dùng được bên trong Box và tương đương position: absolute với left/bottom. Lớp phủ này là mẹo designer rất hay dùng để chữ trắng luôn đọc được trên ảnh bất kỳ.

4. opacity khác rgba thế nào?

CSSComposeLàm mờ cái gì
opacity: 0.3Modifier.alpha(0.3f)Cả khối, gồm nền, chữ, icon bên trong
background: rgba(…, 0.3)colors.primary.copy(alpha = 0.3f)Chỉ màu đó, chữ bên trong vẫn rõ

copy(alpha = ...) nghĩa là "chép màu này ra một bản mới, chỉ đổi độ trong suốt". Màu gốc colors.primary không bị thay đổi. Chữ f sau số (0.3f) là cách Kotlin ghi số thập phân kiểu Float, bạn đã gặp ở weight(1f). Giá trị đi từ 0f (trong suốt hẳn) đến 1f (đặc hoàn toàn), giống CSS.

5. Nhiệm vụ

Bước 1: trang mới. Tạo EffectPage.kt, route "effect", dùng AppPage giống ProfilePage, và thêm một link từ TemplatePage tới trang này.

Bước 2: thêm màu surface vào theme. Mở ui/theme/Color.kt. Thêm surface vào đủ 4 chỗ giống cách bạn đã làm với các màu khác: LightMode (0xFFFFFFFF), DarkMode (0xFF1E2228), data class AppColors, và hai biến LightAppColors / DarkAppColors. Nếu thiếu một chỗ, build sẽ báo lỗi và chỉ ra chỗ còn thiếu.

Bước 3: banner gradient. Code mẫu (đã build thử, chạy được):

Box(
    modifier = Modifier
        .fillMaxWidth()
        .height(100.dp)
        .background(
            brush = Brush.horizontalGradient(listOf(colors.primary, colors.secondary)),
            shape = RoundedCornerShape(12.dp)
        ),
    contentAlignment = Alignment.Center // căn giữa con bên trong, giống flex center
) {
    Text(text = "Chào mừng!", color = colors.white, style = titleMedium)
}

Bước 4: card có bóng đổ. Tự viết theo mục 2: một Column có shadow(8.dp) → background(colors.surface) → padding(16.dp), bên trong có tiêu đề in đậm và một dòng mô tả. Thử đổi elevation thành 2.dp rồi 16.dp để thấy khác biệt. Thêm spotColor = colors.primary vào shadow(...) để có bóng màu xanh, giống box-shadow có màu.

Bước 5: ảnh có chữ. Tự viết theo mục 3: dùng R.drawable.banner, cao 160dp, bo góc 12dp, chữ "Đà Lạt mùa hoa" màu trắng ở góc dưới trái. Thử xoá lớp phủ để thấy chữ khó đọc thế nào khi ảnh sáng.

Bước 6: hai hàng opacity. Mỗi hàng là một Row có 3 Box (cao 40dp, weight(1f), bo góc 8dp, có chữ "100%", "60%", "30%" ở giữa). Hàng 1: nền colors.primary và Modifier.alpha(...). Hàng 2: nền colors.primary.copy(alpha = ...). Chú ý: trong Row, giữa các ô cần khoảng cách, dùng horizontalArrangement = Arrangement.spacedBy(8.dp) (giống gap: 8px).

Bước 7: kiểm tra. Build, chạy, chuyển Light/Dark và so sánh với hình kết quả.

Bài này chưa tách component mới: card có bóng đổ sẽ thành AppCard ở Bài 10, dùng lại đúng những gì bạn làm ở Bước 4. Muốn chữ có màu gradient (background-clip: text) hoặc nút bấm có nền gradient? Hãy hỏi agent. Báo "xong bài 8" khi xong.
