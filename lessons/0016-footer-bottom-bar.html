Bài 16 / Khung app (học sớm theo yêu cầu) · Lộ trình

Footer: thanh tab dưới (ion-tab-bar) và footer cố định chứa nút (ion-footer)

Bài 15: xong. AppDrawer có logo, phần giữa cuộn được nhờ weight(1f), phần cuối "Version 1.0", và mục Logout màu đỏ nhờ cờ isDanger. Còn vài điểm nhỏ, xem phần nhận xét trong tin nhắn của agent.

Bài này làm 2 component theo đúng 2 thiết kế của bạn:

  • Loại 1, AppNavBar: thanh tab dưới có 4–5 nút icon + chữ để chuyển giữa các trang chính, có nút tròn màu đặc biệt (như SOS).
  • Loại 2, AppBottomBar: footer đứng yên ở đáy, chứa bất kỳ thứ gì bạn muốn: một nút, hai nút, chữ, hoặc component khác.

Ở cả hai loại, nội dung trang tự cuộn bên dưới footer, và phần cuối nội dung không bị footer che.

Kết quả mong đợi

Cả hai hình đều cuộn được. Ở hình trái, bấm các tab để đổi tab đang chọn.

Chú ý khi so sánh: cả hai footer có nền colors.backgroundCard, bo 2 góc trên 24dp và bóng đổ hướng lên trên. Footer nằm trên thanh điều hướng của điện thoại (vạch ngang ở đáy), không bị nó che. Loại 1: tab đang chọn có nền viên thuốc colors.primary mờ 12%, icon và chữ colors.primary. Tab chưa chọn màu colors.secondary. Nút SOS là vòng tròn colors.danger. Loại 2: nút rộng hết chiều ngang, cách mép 24dp.

Giống topBar ở Bài 14: bottomBar nằm ngoài vùng cuộn nên đứng yên. Scaffold đo chiều cao footer rồi đưa vào innerPadding, nên phần cuối nội dung luôn nằm trên footer. Bạn đã sửa AppPage để verticalScroll đứng trước padding, nên nội dung còn cuộn xuống dưới footer được, đúng như bạn muốn.

2. Loại 1: thanh tab, NavigationBar

IonicCompose
<ion-tab-bar>NavigationBar { ... }
<ion-tab-button tab="home">NavigationBarItem(...)
<ion-icon> + <ion-label>icon = { Icon(...) }, label = { Text(...) }
tab đang mở (.tab-selected)selected = item.route == currentRoute
màu tab chọn / chưa chọnNavigationBarItemDefaults.colors(...), trong đó indicatorColor là màu viên thuốc

Cách làm y hệt AppDrawer của bạn: một data class cho mỗi nút, một danh sách, một forEach. NavigationBar tự chia đều chiều ngang cho các nút và tự chừa chỗ cho thanh điều hướng của điện thoại. Material khuyên dùng 3 đến 5 nút.

Chuyển tab mà không chồng trang

Ở Bài 14 và 15, mỗi lần navigate là chồng thêm một trang vào lịch sử. Với thanh tab, chuyển qua lại giữa các tab nhiều lần sẽ làm nút Back phải đi lùi qua cả chục trang. Cách chuẩn cho thanh tab:

navController.navigate(item.route) {
    popUpTo("menu") { saveState = true } // dọn lịch sử về tới tab Home, nhớ lại trạng thái trang
    launchSingleTop = true               // đang ở trang đó rồi thì không mở thêm
    restoreState = true                  // quay lại tab cũ thì trả lại trạng thái (vị trí cuộn...)
}

Kết quả giống tab của Ionic: lịch sử chỉ có tab Home và tab đang mở. Bấm Back từ một tab bất kỳ thì về Home. Bạn chỉ cần nhớ công thức 3 dòng này cho thanh tab. Lưu ý: popUpTo("menu") chỉ dọn được khi trang Home ("menu") đã có trong lịch sử. Vì vậy khi thử, hãy vào Home trước rồi mới chuyển tab. Trong app thật, Home thường là trang mở đầu tiên sau khi đăng nhập.

Nút tròn đặc biệt (SOS)

data class AppNavItem(
    val label: String,
    val route: String,
    val icon: ImageVector,
    val circleColor: Color? = null, // có màu = vẽ thành nút tròn; null = nút thường
)

Giống cờ isDanger trong AppDrawer của bạn, nhưng thay vì true/false thì là một màu "có thể không có" (Color?, như onBack ở Bài 14). Khi vẽ icon:

val circle = item.circleColor
if (circle != null) {
    // Box tròn màu circle, icon trắng ở giữa
} else {
    Icon(item.icon, contentDescription = null) // nút thường
}

3. Loại 2: footer cố định chứa gì cũng được, AppBottomBar

Không cần component Material nào. Chỉ là một Column có nền, bo góc, bóng hướng lên, và một slot content giống AppCard. Bạn truyền gì vào thì footer hiện cái đó:

CSS 
.footer {
  position: fixed; bottom: 0;
  left: 0; right: 0;
  padding: 16px 24px;
  padding-bottom: calc(16px +
    env(safe-area-inset-bottom));
  border-radius: 24px 24px 0 0;
  box-shadow: 0 -4px 12px
    rgba(0,0,0,.1);
}
Compose 
Column(
  modifier = Modifier
    .fillMaxWidth()
    .boxShadow(..., y = (-4).dp, ...)
    .background(colors.backgroundCard,
                shape)
    .navigationBarsPadding() // safe-area
    .padding(horizontal = 24.dp,
             vertical = 16.dp),
  content = content
)

y = (-4).dp: số âm đẩy bóng lên trên, giống box-shadow: 0 -4px. navigationBarsPadding() giống env(safe-area-inset-bottom): chừa chỗ cho thanh điều hướng của điện thoại để nút không bị vạch ngang che.

4. Nhiệm vụ

Bước 1: tạo ui/components/layout/AppNavBar.kt. Code mẫu (đã build thử, chạy được). Bạn có thể đổi route theo các trang chính bạn muốn:

data class AppNavItem(
    val label: String,
    val route: String,
    val icon: ImageVector,
    val circleColor: Color? = null, // có màu = nút tròn đặc biệt
)

@Composable
fun AppNavBar(
    navController: NavController,
    currentRoute: String, // route của trang đang mở
) {
    // danh sách đặt trong hàm vì cần đọc colors (chỉ đọc được trong @Composable)
    val navItems = listOf(
        AppNavItem("SOS", "dialog", Icons.Default.Warning, circleColor = colors.danger),
        AppNavItem("Home", "menu", Icons.Default.Home),
        AppNavItem("Card", "card2", Icons.Default.Star),
        AppNavItem("Profile", "profile", Icons.Default.Person),
        AppNavItem("Setting", "checkbox", Icons.Default.Settings),
    )
    val shape = RoundedCornerShape(topStart = 24.dp, topEnd = 24.dp)

    NavigationBar(
        containerColor = colors.backgroundCard,
        modifier = Modifier
            .boxShadow(color = colors.black.copy(alpha = 0.1f), y = (-4).dp, blur = 12.dp, shape = shape)
            .clip(shape) // bo 2 góc trên
    ) {
        navItems.forEach { item ->
            NavigationBarItem(
                selected = item.route == currentRoute,
                onClick = {
                    if (item.route != currentRoute) {
                        navController.navigate(item.route) {
                            popUpTo("menu") { saveState = true }
                            launchSingleTop = true
                            restoreState = true
                        }
                    }
                },
                icon = {
                    val circle = item.circleColor
                    if (circle != null) {
                        Box(
                            modifier = Modifier
                                .size(44.dp)
                                .background(circle, CircleShape),
                            contentAlignment = Alignment.Center
                        ) {
                            Icon(item.icon, contentDescription = null, tint = colors.white)
                        }
                    } else {
                        Icon(item.icon, contentDescription = null)
                    }
                },
                label = { Text(item.label) },
                colors = NavigationBarItemDefaults.colors(
                    selectedIconColor = colors.primary,
                    selectedTextColor = colors.primary,
                    indicatorColor = colors.primary.copy(alpha = 0.12f), // viên thuốc
                    unselectedIconColor = colors.secondary,
                    unselectedTextColor = colors.secondary,
                )
            )
        }
    }
}

Bước 2: gắn vào 4 trang chính (MenuPage, Card2Page, ProfilePage, CheckboxPage). Mỗi trang chỉ thêm 1 dòng vào AppPage, với currentRoute là route của chính trang đó:

AppPage(
    topBar = { ... },
    bottomBar = { AppNavBar(navController = navController, currentRoute = "menu") }
) { ... }

Thử chuyển tab nhiều lần rồi bấm Back của điện thoại: phải về Home, không lùi qua từng tab đã mở.

Bước 3: tự viết ui/components/layout/AppBottomBar.kt theo mục 3. Tham số: modifier và content: @Composable ColumnScope.() -> Unit. Code mẫu đã build thử nằm ở cột Compose của mục 3, bạn chỉ cần thêm phần khai báo hàm và val shape.

Bước 4: trang VerifyPage, route "verify", theo hình bên phải: AppTopBar("Verify Email") có nút Back, nội dung là vòng tròn có dấu "!", 2 dòng chữ căn giữa, và footer:

bottomBar = {
    AppBottomBar {
        AppButton(text = "Resend Link", onClick = { }, modifier = Modifier.fillMaxWidth())
    }
}

Thêm nhiều Text vào nội dung để trang đủ dài, rồi cuộn để thấy nút đứng yên. Thử thay nội dung footer bằng 2 nút nằm ngang (Row + weight(1f)) hoặc một dòng chữ để thấy slot nhận gì cũng được.
