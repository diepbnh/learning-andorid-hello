5 bài tập AlertDialog, từ dễ đến khó

Bạn đã có DialogPage với tiêu đề, link "Template" và route "dialog". Giờ thêm lần lượt 5 nút vào trang, mỗi nút mở một AlertDialog. Làm theo thứ tự, chạy thử sau mỗi bài. Bài 1 có code mẫu đầy đủ, các bài sau chỉ có gợi ý để bạn tự gõ.

Kết quả mong đợi (sau cả 5 bài)

Hình dưới bấm được. Thử bài 3: bấm "Đăng xuất" trong hộp thoại thì dòng trạng thái đổi. Thử bài 5: bấm ra ngoài hộp thoại sẽ không đóng được.

Chú ý khi so sánh: nút của AlertDialog chỉ có chữ, không có nền, và nằm bên phải. Khi có 2 nút, "Huỷ" ở bên trái nút đồng ý. Bài 4 có icon cảnh báo màu đỏ ở trên và tiêu đề căn giữa: Material tự căn giữa khi có icon. Nút "Xoá" chữ đỏ. Ở Dark Mode, nền hộp là xám tối.

Bài 1: Thông báo 1 nút (chép theo mẫu)

Thêm State showInfo ở đầu hàm, thêm nút "Bài 1: Thông báo" sau Spacer, rồi viết hộp thoại ngoài AppPage { }:

@Composable
fun DialogPage(modifier: Modifier = Modifier, navController: NavController) {
    var showInfo by remember { mutableStateOf(false) }

    AppPage(modifier = modifier) {
        // ... Box tiêu đề của bạn ...
        AppButton(
            text = "Bài 1: Thông báo",
            onClick = { showInfo = true },
            modifier = Modifier.fillMaxWidth()
        )
    }

    if (showInfo) {
        AlertDialog(
            onDismissRequest = { showInfo = false },
            title = { Text("Đã lưu") },
            text = { Text("Thông tin của bạn đã được lưu thành công.") },
            confirmButton = {
                TextButton(onClick = { showInfo = false }) {
                    Text("OK", color = colors.primary)
                }
            },
            containerColor = colors.surface,
            titleContentColor = colors.text,
            textContentColor = colors.text,
        )
    }
}

Import mới: AlertDialog, TextButton (trong androidx.compose.material3), getValue, setValue, mutableStateOf (trong androidx.compose.runtime).

  • Bấm OK, bấm vùng tối, bấm Back: cả 3 đều đóng.
  • Bấm vào bên trong hộp: không đóng.

Bài 2: Xác nhận 2 nút (tự gõ)

State showLeave, nút "Bài 2: Xác nhận". Tiêu đề "Thoát trang?", nội dung "Những thay đổi chưa lưu sẽ bị mất.", nút phải "Thoát", nút trái "Ở lại".

Gợi ý: nút trái nằm trong ô dismissButton = { ... }, viết giống hệt confirmButton. Lúc này cả 2 nút chỉ cần đóng hộp thoại.

  • "Ở lại" bên trái, "Thoát" bên phải.

Bài 3: Nút làm 2 việc (tự gõ)

Ở 2 bài trước, bấm nút chỉ để đóng. Bài này bấm nút vừa đổi dữ liệu, vừa đóng.

  1. Thêm State isLoggedIn, mặc định true.
  2. Dưới tiêu đề trang, thêm một Text hiện "Trạng thái: Đã đăng nhập" hoặc "Trạng thái: Đã đăng xuất" tuỳ theo isLoggedIn.
  3. State showLogout, nút "Bài 3: Đăng xuất thật". Hộp thoại "Đăng xuất?" / "Bạn có chắc muốn đăng xuất không?", 2 nút "Huỷ" và "Đăng xuất".
  4. Nút "Đăng xuất" đặt isLoggedIn = false và đóng hộp thoại. Nút "Huỷ" chỉ đóng.

Gợi ý: trong { } viết được nhiều dòng, mỗi dòng là một việc, giống thân hàm onclick trên web. Chữ đổi theo State thì dùng if ... else ngay trong text = , giống toán tử ? : của JavaScript:

text = if (isLoggedIn) "..." else "..."
  • Bấm Huỷ: trạng thái giữ nguyên.
  • Bấm Đăng xuất: trạng thái đổi thành "Đã đăng xuất".
  • Thử thêm: khi đã đăng xuất thì nút Bài 3 bị mờ, không bấm được. AppButton có sẵn tham số enabled.

Bài 4: Có icon, nút nguy hiểm (tự gõ, tham số mới)

AlertDialog còn một ô bạn chưa dùng: icon. Có icon thì Material tự đặt icon lên trên và căn giữa tiêu đề.

Tham số mớiÝ nghĩa
icon = { Icon(Icons.Default.Warning, contentDescription = null) }ô icon, nằm trên tiêu đề
iconContentColor = colors.dangermàu icon, giống titleContentColor

Nội dung: "Xoá ảnh này?" / "Ảnh sẽ bị xoá vĩnh viễn và không khôi phục được.", nút "Huỷ" và nút "Xoá" chữ màu colors.danger.

Import: androidx.compose.material3.Icon, androidx.compose.material.icons.Icons, androidx.compose.material.icons.filled.Warning.

  • Icon đỏ ở trên, tiêu đề căn giữa.
  • Chữ "Xoá" màu đỏ, chữ "Huỷ" màu primary.

Bài 5: Bắt buộc bấm nút (thử thách)

Hộp "Điều khoản mới" / "Chúng tôi đã cập nhật điều khoản sử dụng. Bạn cần đồng ý để tiếp tục.", chỉ có 1 nút "Tôi đồng ý". Người dùng không được đóng bằng cách bấm ra ngoài hay bấm Back.

Gợi ý: AlertDialog cũng nhận tham số properties = DialogProperties(...) giống Dialog ở Bài 10 mục 2. Bạn cần tắt 2 thứ. Tự đoán tên thuộc tính thứ hai nhé: thuộc tính thứ nhất là dismissOnClickOutside.

  • Bấm vùng tối: không đóng.
  • Bấm Back: không đóng.
  • Bấm "Tôi đồng ý": đóng.

Làm xong bài nào thì nhắn "check bài 1", "check bài 2"... để agent xem code, hoặc làm hết rồi nhắn "check DialogPage". Code của 2 tham số mới (icon, properties) đã được build thử, chạy được. Xong 5 bài thì chuyển sang Dialog tự thiết kế (Bài 10b, số 3).
