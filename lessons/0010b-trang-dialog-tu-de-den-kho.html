Trang Dialog: 8 kiểu hộp thoại, từ dễ đến khó

Bài 10 dạy 3 kiểu cơ bản (Dialog, AlertDialog, Bottom Sheet). Bài này gom tất cả vào một trang showcase giống trang demo component của Ionic: mỗi nút mở một kiểu hộp thoại, xếp theo 3 mức Dễ / Vừa / Khó. Nếu bạn chưa làm ModalPage của Bài 10 thì làm luôn trang này, thay cho Bài 10 Bước 1.

Kết quả mong đợi

Một trang Dialog có 8 nút. Hai dòng đầu trang hiện giá trị hiện tại; hộp thoại số 5 và 6 sẽ đổi được 2 giá trị này. Hình dưới bấm được: thử chọn ngôn ngữ, đổi tên, để trống tên rồi bấm Lưu, và thử bấm ra ngoài hộp thoại số 4.

Chú ý khi so sánh: tất cả hộp thoại dùng nền colors.surface, chữ colors.text. Số 3 có vòng tròn đỏ nhạt chứa icon cảnh báo. Số 4 không đóng khi bấm ra ngoài hay bấm Back, chỉ đóng khi bấm nút. Số 5 và 6 chỉ đổi giá trị trên trang khi bấm Chọn / Lưu; bấm Huỷ hoặc ra ngoài thì giữ nguyên giá trị cũ. Số 8 phủ kín màn hình, nội dung cuộn được, nút "Tôi đồng ý" luôn nằm dưới đáy.

2. Khung trang

Giống Bài 10: mỗi hộp thoại có 1 State true/false. Thêm 2 State giữ giá trị của trang (ngôn ngữ, tên) để hộp thoại 5 và 6 có cái mà đổi.

@Composable
fun DialogPage(modifier: Modifier = Modifier, navController: NavController) {
    // State mở/đóng: 8 cái, mỗi hộp thoại 1 cái
    var showInfo by remember { mutableStateOf(false) }
    var showConfirm by remember { mutableStateOf(false) }
    // ... showDelete, showUpdate, showLanguage, showRename, showSheet, showTerms

    // State giá trị của trang
    var language by remember { mutableStateOf("Tiếng Việt") }
    var name by remember { mutableStateOf("Hong Diep") }

    Box(modifier = modifier.fillMaxSize()) {
        AppPage {
            // tiêu đề + link Back như ToggleButtonPage
            Text("Ngôn ngữ: $language")
            Text("Tên: $name")

            Text("Dễ", style = titleMedium)
            AppButton(text = "1. Thông báo 1 nút", onClick = { showInfo = true })
            // ... 7 nút còn lại, có Spacer ở giữa
        }

        // 7. Bottom Sheet (AnimatedVisibility) đặt Ở ĐÂY: trong Box, sau AppPage
        BackHandler(enabled = showSheet) { showSheet = false }
    }

    // 1–6 và 8 dùng Dialog / AlertDialog: đặt ở đây, ngoài Box
    if (showInfo) { ... }
    if (showConfirm) { ... }
    // ...
}

"Ngôn ngữ: $language" là cách chèn biến vào chuỗi, giống `Ngôn ngữ: ${language}` trong JavaScript.

3. Mức Dễ

Số 1: Thông báo 1 nút

Chỉ là AlertDialog của Bài 10 nhưng bỏ tham số dismissButton. Không truyền thì Material không vẽ nút đó, giống ô trống trong layout.

if (showInfo) {
    AlertDialog(
        onDismissRequest = { showInfo = false },
        title = { Text("Đã lưu") },
        text = { Text("Thông tin của bạn đã được lưu thành công.") },
        confirmButton = {
            TextButton(onClick = { showInfo = false }) {
                Text("OK", color = colors.primary)
            }
        },
        containerColor = colors.surface,
        titleContentColor = colors.text,
        textContentColor = colors.text,
    )
}

Số 2: Xác nhận 2 nút

Chính là Bài 10 Bước 3 ("Đăng xuất?"). Tự viết lại, không cần code mẫu.

4. Mức Vừa

Số 3: Có icon + nút nguy hiểm

Lấy Dialog "Xoá ảnh này?" của Bài 10 Bước 2, thêm 2 thứ: Column căn giữa (horizontalAlignment = Alignment.CenterHorizontally) và một vòng tròn icon ở trên cùng. Vòng tròn là Box bo tròn hẳn, giống border-radius: 50%:

Box(
    contentAlignment = Alignment.Center, // icon nằm giữa vòng tròn
    modifier = Modifier
        .size(56.dp)
        .background(colors.danger.copy(alpha = 0.15f), CircleShape) // đỏ nhạt 15%
) {
    Icon(
        imageVector = Icons.Default.Warning,
        contentDescription = null, // icon trang trí, không cần đọc cho người khiếm thị
        tint = colors.danger
    )
}
Spacer(modifier = Modifier.height(12.dp))
Text("Xoá ảnh này?", style = titleMedium, color = colors.text)
// ... phần còn lại như Bài 10 Bước 2

.copy(alpha = 0.15f) bạn đã gặp ở Bài 8, giống rgba(..., 0.15). Nếu đã làm AppDialog (Bài 10 Bước 5), thử thêm tham số icon: ImageVector? = null: có icon thì vẽ vòng tròn, null thì không.

Số 4: Bắt buộc bấm nút

Dùng cho trường hợp người dùng phải chọn, ví dụ app bắt cập nhật. Tắt cả 2 cách đóng tự động:

Dialog(
    onDismissRequest = { }, // để trống: không làm gì khi bấm ra ngoài
    properties = DialogProperties(
        dismissOnClickOutside = false, // bấm vùng tối: không đóng
        dismissOnBackPress = false     // bấm Back: không đóng
    )
) {
    // Column: tiêu đề, câu giải thích, 1 AppButton "Cập nhật ngay"
    // nút này mới là chỗ duy nhất đặt showUpdate = false
}

Số 5: Chọn 1 trong danh sách

Đây là điểm mới quan trọng nhất của bài: State tạm. Nếu bấm radio mà đổi language ngay, thì bấm Huỷ cũng không quay lại được. Vì vậy trong hộp thoại có một State riêng selected, chỉ khi bấm Chọn mới chép nó vào language. Giống form Ionic: sửa trên bản sao, bấm Save mới ghi vào dữ liệu thật.

if (showLanguage) {
    val languages = listOf("Tiếng Việt", "English", "日本語")
    // State tạm: khai báo BÊN TRONG if, nên mỗi lần mở lại bắt đầu từ language hiện tại
    var selected by remember { mutableStateOf(language) }

    Dialog(onDismissRequest = { showLanguage = false }) {
        Column(/* nền surface, bo 16.dp, padding 24.dp như số 3 */) {
            Text("Chọn ngôn ngữ", style = titleMedium, color = colors.text)

            languages.forEach { item ->
                Row(
                    verticalAlignment = Alignment.CenterVertically,
                    modifier = Modifier
                        .fillMaxWidth()
                        .clickable { selected = item } // bấm cả dòng, không chỉ bấm chấm tròn
                ) {
                    RadioButton(
                        selected = selected == item,
                        onClick = { selected = item },
                        colors = RadioButtonDefaults.colors(selectedColor = colors.primary)
                    )
                    Text(item, color = colors.text)
                }
            }

            Row(horizontalArrangement = Arrangement.End, modifier = Modifier.fillMaxWidth()) {
                TextButton(onClick = { showLanguage = false }) { Text("Huỷ", color = colors.primary) }
                TextButton(onClick = {
                    language = selected   // lúc này mới ghi vào State thật
                    showLanguage = false
                }) { Text("Chọn", color = colors.primary) }
            }
        }
    }
}

forEach bạn đã tự dùng khi vẽ danh sách, giống *ngFor. RadioButton giống <ion-radio>: nó không tự nhớ mình được chọn, bạn phải nói cho nó biết qua selected = ....

5. Mức Khó

Số 6: Form nhập liệu

Kết hợp số 5 (State tạm) với cách bạn đã làm báo lỗi ở SignUpPage. Dùng lại AppFormField:

if (showRename) {
    var newName by remember { mutableStateOf(name) } // State tạm
    var isError by remember { mutableStateOf(false) }

    Dialog(onDismissRequest = { showRename = false }) {
        Column(/* như số 3 */) {
            Text("Đổi tên", style = titleMedium, color = colors.text)
            Spacer(modifier = Modifier.height(12.dp))
            AppFormField(
                label = "Tên hiển thị",
                value = newName,
                onValueChange = {
                    newName = it
                    isError = false // gõ lại thì tắt báo lỗi
                },
                placeholder = "Nhập tên...",
                isError = isError,
                errorMessage = "Tên không được để trống"
            )
            Spacer(modifier = Modifier.height(20.dp))
            // Row 2 nút Huỷ / Lưu như Bài 10 Bước 2. Nút Lưu:
            AppButton(
                text = "Lưu",
                onClick = {
                    if (newName.isBlank()) {
                        isError = true        // không đóng, hiện lỗi
                    } else {
                        name = newName        // ghi vào State thật
                        showRename = false
                    }
                }
            )
        }
    }
}

isBlank() đúng khi chuỗi rỗng hoặc chỉ toàn dấu cách, giống !value.trim() trên web.

Số 7: Bottom Sheet

Chính là Bài 10 Bước 4. Nhớ: phần này nằm trong Box, sau AppPage, không nằm cùng chỗ với các if (showX) khác.

Số 8: Toàn màn hình

Mặc định Dialog giới hạn chiều rộng (như max-width của modal). Tắt giới hạn đó rồi cho Column fillMaxSize(). Bố cục 3 phần: thanh trên, nội dung cuộn, nút dưới đáy.

if (showTerms) {
    Dialog(
        onDismissRequest = { showTerms = false },
        properties = DialogProperties(usePlatformDefaultWidth = false) // bỏ max-width
    ) {
        Column(
            modifier = Modifier
                .fillMaxSize()
                .background(colors.backgroundBody) // màu nền giống trang, không phải surface
        ) {
            // 1. Thanh trên: nút X + tiêu đề
            Row(verticalAlignment = Alignment.CenterVertically) {
                IconButton(onClick = { showTerms = false }) {
                    Icon(Icons.Default.Close, contentDescription = "Đóng", tint = colors.text)
                }
                Text("Điều khoản sử dụng", style = titleMedium, color = colors.text)
            }
            // 2. Nội dung: chiếm hết chỗ còn lại và cuộn được
            Column(
                modifier = Modifier
                    .weight(1f)
                    .verticalScroll(rememberScrollState())
                    .padding(horizontal = 20.dp)
            ) {
                // 8 đoạn Text "Điều 1. ..." (dữ liệu giả)
            }
            // 3. Nút dưới đáy
            AppButton(
                text = "Tôi đồng ý",
                onClick = { showTerms = false },
                modifier = Modifier
                    .fillMaxWidth()
                    .padding(20.dp)
                    .navigationBarsPadding()
            )
        }
    }
}

weight(1f) ở đây giống flex: 1: nội dung giữa "phình ra" lấp chỗ trống, đẩy nút xuống đáy. Nếu thiếu weight(1f), đoạn chữ dài sẽ đẩy nút ra khỏi màn hình.

6. Nhiệm vụ

Bước 1: trang mới. Tạo DialogPage.kt, route "dialog", thêm vào MainActivity và thêm link "Dialog" trong TemplatePage (dòng có ToggleButton). Viết khung trang ở mục 2 với 8 nút, chưa cần hộp thoại nào.

Bước 2: mức Dễ (số 1, 2). Chạy thử trước khi làm tiếp.

Bước 3: mức Vừa (số 3, 4, 5). Với số 5: mở, chọn English, bấm Huỷ. Trang phải vẫn ghi "Tiếng Việt". Mở lại, chấm tròn phải nằm ở "Tiếng Việt".

Bước 4: mức Khó (số 6, 7, 8). Với số 6: xoá hết tên, bấm Lưu phải hiện lỗi và không đóng.

Bước 5: kiểm tra. Với mỗi hộp thoại: bấm vùng tối, bấm bên trong, bấm Back, đổi Light/Dark. Riêng số 4 thì bấm vùng tối và Back đều không có tác dụng.

Import mới (Android Studio thường tự gợi ý bằng Alt+Enter): androidx.compose.material3.RadioButton, RadioButtonDefaults, IconButton, androidx.compose.material.icons.filled.Warning, ...filled.Close, androidx.compose.ui.window.DialogProperties, androidx.compose.foundation.shape.CircleShape.

Code mẫu trong bài đã được build thử. Gõ xong thì báo agent "check DialogPage" để kiểm tra, hoặc báo "xong bài 10b".
