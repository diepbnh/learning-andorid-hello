Bài 14 / Khung app (học sớm theo yêu cầu) · Lộ trình

Header cho trang: TopAppBar, giống ion-header + ion-toolbar

Bài 13: xong phần UI. AppRadioGroup có selectableGroup, bấm được cả dòng, và có thêm radioScale. Nhớ thêm verticalAlignment = Alignment.CenterVertically vào Row để chữ nằm giữa với nút radio.

Vì sao cần bài này: trang nào của bạn cũng tự dựng header bằng Box + link "Template" + Text tiêu đề, và chép lại ở mỗi trang. Bài này thay chúng bằng một component dùng chung AppTopBar, với 3 quy tắc: tiêu đề canh giữa, có nút Back, cố định khi cuộn. Phần duy nhất mỗi trang tự quyết định là icon bên phải.

Kết quả mong đợi

Ba trang, cùng một header AppTopBar, chỉ khác nhau phần icon bên phải. Điểm chung: tiêu đề luôn ở giữa, nút Back bên trái, header cố định khi cuộn. Khung đầu tiên cuộn được: thử cuộn để thấy header đứng yên, nội dung trôi bên dưới.

Chú ý khi so sánh: tiêu đề nằm chính giữa màn hình ở cả 3 trang, kể cả trang Checkbox chỉ có nút Back bên trái (CenterAlignedTopAppBar tự canh giữa, bạn không cần thêm khoảng trống bên phải). Header nền colors.primary, chữ và icon colors.white (ở Dark Mode của bạn là màu đen), rộng sát hai mép màn hình và không trôi theo khi cuộn. Nội dung bắt đầu bên dưới header. Không còn link "Template" chữ gạch chân, thay bằng nút mũi tên Back.

1. AppPage của bạn đã có sẵn chỗ cho header

  </ion-toolbar>
</ion-header>
<ion-content>

</ion-content>
Compose 
AppPage(
    topBar = {
        TopAppBar(...)   // ion-header
    }
) {
    // nội dung trang  // ion-content
}

Mở AppPage.kt: tham số topBar đã có từ lâu và được chuyển vào Scaffold. Scaffold giống ion-page: nó tự đặt header lên trên cùng và tự đẩy nội dung xuống dưới header (qua innerPadding), nên nội dung không bị che. Bạn chỉ cần truyền header vào.

Vì sao header đặt vào topBar thì cố định khi cuộn?

Trong AppPage, chỉ phần nội dung (Column có verticalScroll) là cuộn được. topBar nằm ngoài vùng cuộn đó, nên đứng yên:

Header cũ của bạn (Box trong nội dung)topBar
Nằm ở đâubên trong Column cuộn đượcngoài vùng cuộn, do Scaffold giữ
Khi cuộntrôi lên mất cùng nội dungđứng yên ở trên cùng
Giống CSSthẻ bình thường trong trangposition: fixed; top: 0 (hoặc sticky)

Vậy là chỉ cần chuyển header vào topBar, bạn có header cố định mà không phải viết thêm gì. Bạn thử cuộn một trang dài (ví dụ CardPage) với header kiểu cũ để thấy nó trôi mất.

2. Cấu tạo một TopAppBar

IonicTham số ComposeChứa gì
<ion-buttons slot="start"><ion-back-button>navigationIcon = { ... }nút Back hoặc nút menu
<ion-title>title = { Text(...) }tiêu đề
<ion-buttons slot="end">actions = { ... }các nút bên phải (tìm kiếm, thông báo...)
color="primary"colors = TopAppBarDefaults.topAppBarColors(...)màu nền, màu chữ, màu icon

Có 2 loại hay dùng: TopAppBar (tiêu đề bên trái, kiểu Android) và CenterAlignedTopAppBar (tiêu đề ở giữa, kiểu iOS, giống Ionic mặc định trên iPhone). Cách dùng giống hệt nhau. App của bạn muốn tiêu đề ở giữa, nên bài này dùng CenterAlignedTopAppBar.

IconButton là nút chỉ có icon, có sẵn vùng bấm 48dp và hiệu ứng gợn sóng, giống <ion-button fill="clear"><ion-icon>. Bạn đã dùng nó cho nút Back trong CardPage.

3. Lỗi "experimental" và @OptIn

Viết TopAppBar lần đầu, build sẽ báo lỗi:

This material API is experimental and is likely to change or to be removed in the future.

Nghĩa là Google vẫn coi component này là "bản thử nghiệm", có thể đổi trong tương lai. Muốn dùng thì bạn phải xác nhận bằng một dòng đặt phía trên hàm, giống tick "Tôi đồng ý" trước khi dùng:

@OptIn(ExperimentalMaterial3Api::class)
@Composable
fun AppTopBar(...) { ... }

Trên thực tế TopAppBar đã ổn định và được dùng rất rộng rãi. Đây chỉ là thủ tục.

4. Tham số "có thể không có": onBack: (() -> Unit)? = null

Trang chủ thì không có nút Back, trang con thì có. Dấu ? sau kiểu nghĩa là "được phép là null" (không có gì). Mặc định = null là không có nút Back:

navigationIcon = {
    if (onBack != null) {       // != là "khác", ngược với ==
        IconButton(onClick = onBack) {
            Icon(Icons.AutoMirrored.Filled.ArrowBack, contentDescription = "Back")
        }
    }
}

Giống Ionic: trang nào muốn có nút Back thì đặt <ion-back-button>, trang nào không thì bỏ đi. Ở đây trang chỉ cần truyền onBack = { navController.popBackStack() } hoặc không truyền gì.

actions: @Composable RowScope.() -> Unit = {} là một slot giống content của AppCard. Các nút bên trong xếp thành hàng ngang (RowScope), và mặc định {} là không có nút nào.

5. Nhiệm vụ

Chia làm 2 phần. Phần A (hôm nay): chèn một header bình thường thẳng vào ProfilePage, chưa làm component. Phần B (buổi sau): khi đã quen, gom nó thành component AppTopBar dùng chung.

Phần A: chèn header bình thường vào ProfilePage

Bước A1: xoá header cũ. Trong ProfilePage, xoá cả khối Box đầu tiên (chứa IconButton Back và Text("Profile Page")) và Spacer 15dp ngay sau nó.

Bước A2: truyền header vào topBar của AppPage. Bắt đầu đơn giản nhất, chỉ có tiêu đề:

AppPage(
    modifier = modifier,
    topBar = {
        CenterAlignedTopAppBar(
            title = { Text("Profile") }
        )
    }
) {
    // nội dung cũ giữ nguyên (banner, avatar, ...)
}

Build: sẽ báo lỗi experimental (mục 3). Thêm @OptIn(ExperimentalMaterial3Api::class) phía trên @Composable fun ProfilePage. Build lại, chạy app, cuộn trang Profile: tiêu đề đứng yên.

Bước A3: thêm nút Back bên trái (đây chính là IconButton bạn vừa xoá ở bước A1, chỉ chuyển chỗ):

CenterAlignedTopAppBar(
    title = { Text("Profile") },
    navigationIcon = {
        IconButton(onClick = { navController.popBackStack() }) {
            Icon(Icons.AutoMirrored.Filled.ArrowBack, contentDescription = "Back")
        }
    }
)

Bước A4: thêm 2 icon bên phải vào actions (chưa cần làm gì khi bấm, để onClick = { }):

    actions = {
        IconButton(onClick = { }) {
            Icon(Icons.Default.Search, contentDescription = "Search")
        }
        IconButton(onClick = { }) {
            Icon(Icons.Default.Notifications, contentDescription = "Notifications")
        }
    }

Bước A5: tô màu theo theme. Mặc định header dùng màu Material, không phải màu app bạn. Thêm colors:

    colors = TopAppBarDefaults.topAppBarColors(
        containerColor = colors.primary,           // nền header
        titleContentColor = colors.white,          // chữ tiêu đề
        navigationIconContentColor = colors.white, // nút Back
        actionIconContentColor = colors.white,     // icon bên phải
    )

Import cần thêm (Android Studio tự gợi ý bằng Alt+Enter, đây là danh sách để đối chiếu):

import androidx.compose.material3.CenterAlignedTopAppBar
import androidx.compose.material3.ExperimentalMaterial3Api
import androidx.compose.material3.TopAppBarDefaults
import androidx.compose.material.icons.filled.Search
import androidx.compose.material.icons.filled.Notifications

Icon, IconButton, Icons, ArrowBack và colors thì ProfilePage đã import sẵn.

Bước A6: kiểm tra so với khung "Profile" ở hình kết quả: tiêu đề ở giữa, Back bên trái, 2 icon bên phải, header sát mép, cuộn thì header đứng yên. Nếu nội dung cách header quá xa, truyền thêm contentPadding = PaddingValues(20.dp) cho AppPage (mặc định top là 40dp).

Muốn thử thêm: chép nguyên khối CenterAlignedTopAppBar sang RadioPage, đổi tiêu đề và icon bên phải. Bạn sẽ thấy mỗi trang phải chép lại ~25 dòng giống hệt nhau, chỉ khác tiêu đề và icon. Đó là lý do có Phần B.

Làm xong Phần A thì báo "xong phần A bài 14" để agent xem code, rồi học tiếp Phần B.

Phần B (buổi sau): gom thành component AppTopBar

Bước B1: tạo ui/components/layout/AppTopBar.kt (cạnh AppPage.kt). Code mẫu (đã build thử, chạy được):

@OptIn(ExperimentalMaterial3Api::class)
@Composable
fun AppTopBar(
    title: String,
    onBack: (() -> Unit)? = null,                  // không truyền = không có nút Back
    actions: @Composable RowScope.() -> Unit = {},  // các nút bên phải
) {
    CenterAlignedTopAppBar(
        title = { Text(text = title, style = titleMedium) },
        navigationIcon = {
            if (onBack != null) {
                IconButton(onClick = onBack) {
                    Icon(
                        imageVector = Icons.AutoMirrored.Filled.ArrowBack,
                        contentDescription = "Back"
                    )
                }
            }
        },
        actions = actions,
        colors = TopAppBarDefaults.topAppBarColors(
            containerColor = colors.primary,
            titleContentColor = colors.white,
            navigationIconContentColor = colors.white,
            actionIconContentColor = colors.white,
        )
    )
}

Để ý: tiêu đề ở giữa và màu sắc được khoá cứng bên trong component, trang không đổi được. Đó là điều bạn muốn: mọi trang giống nhau. Trang chỉ truyền 3 thứ: title, onBack và actions (icon bên phải).

Bước B2: thay header ở ProfilePage (khối CenterAlignedTopAppBar dài ở Phần A) bằng AppTopBar ngắn gọn:

AppPage(
    modifier = modifier,
    topBar = {
        AppTopBar(
            title = "Profile",
            onBack = { navController.popBackStack() },
            actions = {
                IconButton(onClick = { }) { Icon(Icons.Default.Search, contentDescription = "Search") }
                IconButton(onClick = { }) { Icon(Icons.Default.Notifications, contentDescription = "Notifications") }
            }
        )
    }
) { ... }

~25 dòng ở Phần A rút còn ~10 dòng, và trang nào dùng AppTopBar cũng có cùng màu, cùng tiêu đề ở giữa. Nếu muốn giữ một trang kiểu cũ để so sánh như bạn hay làm thì giữ ở CardPage.

Bước B3: dùng ở thêm 2 trang theo hình: RadioPage có 1 icon Lưu (Icons.Default.Check), CheckboxPage không truyền actions. Kiểm tra tiêu đề vẫn ở giữa ở cả 3 trang, và kiểm tra Light/Dark. AppPage có contentPadding top 40dp. Khi đã có header, khoảng này có thể quá lớn, bạn thử truyền contentPadding = PaddingValues(20.dp) cho đẹp.

Bước B4 (thử thách, không bắt buộc): header cố định, đổi màu khi cuộn, giống iOS: chưa cuộn thì header cùng màu nền trang, cuộn thì đổi sang màu card. Header vẫn đứng yên, nhưng "biết" trang đang cuộn để đổi màu nền (đã build thử, chạy được):

val scrollBehavior = TopAppBarDefaults.pinnedScrollBehavior() // pinned = ghim cố định

AppPage(
    modifier = modifier.nestedScroll(scrollBehavior.nestedScrollConnection), // cho header nghe sự kiện cuộn
    topBar = {
        CenterAlignedTopAppBar(
            title = { Text("Profile") },
            scrollBehavior = scrollBehavior,
            colors = TopAppBarDefaults.topAppBarColors(
                containerColor = colors.backgroundBody,         // chưa cuộn: hoà vào nền trang
                scrolledContainerColor = colors.backgroundCard, // đang cuộn: tách khỏi nội dung
                titleContentColor = colors.primary,
                navigationIconContentColor = colors.primary,
                actionIconContentColor = colors.primary,
            )
        )
    }
) { ... }

nestedScroll giống gắn addEventListener('scroll', ...) cho trang để header biết khi nào nội dung đang trôi bên dưới nó. Chữ và icon dùng colors.primary để đọc được trên cả 2 màu nền. Muốn dùng với AppTopBar thì thêm tham số scrollBehavior: TopAppBarScrollBehavior? = null và truyền tiếp vào CenterAlignedTopAppBar. Trang phải đủ dài để cuộn được.
