Bài 7 / Nhóm 1: Trang trí · Lộ trình

Image và Icon: <img>, object-fit, avatar tròn, icon SVG

Bài 6: xong, vượt yêu cầu. Bạn tự vẽ đường kẻ bằng drawBehind để không bị viền đôi, và tự tạo hàng từ dữ liệu bằng data class + forEachIndexed. Từ bài này, mỗi bài học một nhóm thành phần UI mà bạn đã quen trên web. Bài 7 mở đầu Nhóm 1 (Trang trí), phần gần CSS nhất.

Kết quả mong đợi

Một trang Profile: ảnh bìa bo góc, avatar tròn có viền, tên, 3 icon có chữ, và một hàng so sánh 3 kiểu ContentScale. Ảnh trong hình là ảnh minh họa, bạn dùng ảnh thật của mình.

Chú ý khi so sánh: ảnh bìa rộng hết màn hình, cao khoảng 140dp, bo góc 12dp, ảnh bị cắt bớt chứ không méo. Avatar tròn, có viền màu colors.primary. Icon có màu colors.primary và tự đổi màu ở Dark Mode. Ở hàng ContentScale: Crop lấp đầy khung và cắt bớt ảnh, Fit thấy đủ ảnh nhưng có khoảng trống, FillBounds lấp đầy nhưng ảnh bị méo.

1. Chuẩn bị ảnh và icon

Thư mục app/src/main/res/drawable/ là thư mục images/ của app. Có một quy tắc đặt tên mà web không có: tên file chỉ được dùng chữ thường a–z, số 0–9 và dấu gạch dưới _, và không được bắt đầu bằng số. Avatar-User.jpg sẽ làm build lỗi, avatar_user.jpg thì hợp lệ.

  • Ảnh: chép 2 ảnh bất kỳ (jpg/png/webp) vào res/drawable/, đặt tên banner.jpg và avatar.jpg.
  • Icon, cách 1: vào Google Fonts Icons, chọn icon, mở tab Android, tải file XML về, đổi tên thành ic_home.xml, ic_favorite.xml, ic_person.xml rồi chép vào res/drawable/.
  • Icon, cách 2 (từ Figma): export icon ra SVG, rồi trong Android Studio chọn File › New › Vector Asset › Local file và chọn file SVG. Android Studio sẽ đổi SVG thành XML giúp bạn.

Vì sao không dùng bộ Icons.Default... có sẵn như nhiều hướng dẫn cũ? Vì Google không còn khuyên dùng thư viện đó: icon kiểu cũ và làm build chậm đi nhiều. Tải icon dạng XML là cách hiện tại.

2. <img> → Image

HTML 
<img src="images/banner.jpg"
     alt="Ảnh bìa">
Compose 
Image(
  painter = painterResource(R.drawable.banner),
  contentDescription = "Ảnh bìa",
)

R.drawable.banner là "địa chỉ" mà Android tự tạo cho mỗi file trong drawable/, không có đuôi .jpg. Nó khác src của web ở một điểm: nếu gõ sai tên, build báo lỗi ngay, thay vì hiện ảnh vỡ khi chạy. contentDescription chính là alt. Ảnh chỉ để trang trí thì để null.

3. object-fit → ContentScale

CSSComposeKết quả
object-fit: coverContentScale.CropLấp đầy khung, cắt bớt ảnh. Hay dùng nhất cho ảnh bìa và avatar.
object-fit: containContentScale.FitThấy đủ ảnh, có thể dư khoảng trống. Đây là mặc định.
object-fit: fillContentScale.FillBoundsLấp đầy khung bằng cách kéo méo ảnh.

Giống CSS, ContentScale chỉ tạo ra khác biệt khi khung có tỉ lệ khác với ảnh. Vì vậy luôn đặt kích thước cho khung, ví dụ Modifier.fillMaxWidth().height(140.dp) (Customize an image — Android Developers).

4. Bo góc, ảnh tròn, viền

CSSCompose
border-radius: 12px; overflow: hiddenModifier.clip(RoundedCornerShape(12.dp))
border-radius: 50% (ảnh tròn)Modifier.clip(CircleShape)
border: 2px solid cho ảnh tròn.border(2.dp, colors.primary, CircleShape)

Ảnh tròn chỉ tròn đẹp khi khung là hình vuông, ví dụ Modifier.size(96.dp), và có ContentScale.Crop.

5. Icon khác Image ở đâu?

SVG trên web 
svg { fill: currentColor; }
.icon { color: var(--primary); }
Compose 
Icon(
  painter = painterResource(R.drawable.ic_home),
  contentDescription = "Home",
  tint = colors.primary,
)

Icon tô toàn bộ hình bằng một màu tint, giống fill: currentColor. Dùng theme token cho tint thì icon tự đổi màu theo Light/Dark. Ảnh nhiều màu (logo, ảnh chụp) thì dùng Image, vì Image giữ nguyên màu gốc. Kích thước icon chuẩn là 24dp: Modifier.size(24.dp).

6. Nhiệm vụ

Bước 1: trang mới. Tạo ImagePage.kt, route "image", và một link từ TemplatePage đi tới trang này. Nhớ thêm verticalScroll như bạn đã làm ở bài 6.

Bước 2: ảnh bìa. Code mẫu (đã build thử, chạy được):

Image(
    painter = painterResource(R.drawable.banner),
    contentDescription = "Ảnh bìa",
    contentScale = ContentScale.Crop,
    modifier = Modifier
        .fillMaxWidth()
        .height(140.dp)
        .clip(RoundedCornerShape(12.dp))
)

Bước 3: avatar, tên và 3 icon. Tự viết theo hình kết quả. Gợi ý: avatar 96dp đặt giữa bằng Modifier.align(Alignment.CenterHorizontally). Hàng icon là một Row có horizontalArrangement = Arrangement.SpaceAround (giống justify-content: space-around), mỗi phần tử là một Column gồm Icon và Text.

Bước 4: so sánh ContentScale. Một Row có 3 Image cùng dùng R.drawable.banner, khung vuông 80dp, viền 1dp, lần lượt dùng Crop, Fit và FillBounds. Mỗi ảnh có một Text ghi tên kiểu bên dưới.

Bước 5: tách component AppAvatar vào ui/components/image/AppAvatar.kt. Avatar sẽ dùng ở nhiều màn hình (profile, danh sách, comment), nên đây là component nên có cho team:

@Composable
fun AppAvatar(
    @DrawableRes imageRes: Int,
    modifier: Modifier = Modifier,
    size: Dp = 96.dp,
) {
    // Image tròn, ContentScale.Crop, viền 2dp colors.primary
}

R.drawable.avatar thực chất là một con số (Int). Nhãn @DrawableRes báo cho Android Studio biết số này phải là một R.drawable.... Nếu truyền nhầm một số bất kỳ, Android Studio sẽ cảnh báo. Dùng AppAvatar trong ImagePage, và thêm một AppAvatar cỡ nhỏ (48dp) vào TemplatePage.

Bước 6: kiểm tra. Build, chạy, chuyển Light/Dark. Thử đổi tên file thành Banner.jpg (chữ B hoa) rồi build lại để thấy lỗi tên file trông thế nào, sau đó đổi lại tên cũ.
