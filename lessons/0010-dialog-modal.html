Dialog và Modal: hộp thoại nổi trên lớp nền tối, giống ion-modal

Bài 9: xong. Bạn đã đổi tên tham số của AppToggleBox thành showText / hideText, đọc là hiểu ngay. Theo yêu cầu của bạn, bài này học Modal trước. Card và Badge chuyển sang Bài 11.

Kết quả mong đợi

Một trang Modal có 3 nút, mỗi nút mở một kiểu hộp thoại. Khi mở, một lớp nền đen trong suốt phủ lên nội dung trang. Hình dưới đây bấm được: bấm nút để mở, bấm vào vùng tối để đóng.

Chú ý khi so sánh: lớp nền đen mờ 50% phủ toàn màn hình, chữ bên dưới vẫn thấy lờ mờ. Hộp thoại dùng nền colors.surface, nên ở Dark Mode là xám tối chứ không phải trắng. Dialog nằm giữa màn hình. Bottom Sheet trượt từ đáy lên, chỉ bo 2 góc trên. Bấm vào vùng tối hoặc bấm nút Back của điện thoại thì hộp thoại đóng. Bấm vào bên trong hộp thoại thì không đóng.

1. Ý tưởng chính: modal = State + if

Ionic 
<ion-button (click)="isOpen = true">
  Mở
</ion-button>

<ion-modal [isOpen]="isOpen"
  (didDismiss)="isOpen = false">
  ...
</ion-modal>
Compose 
var isOpen by remember { mutableStateOf(false) }

AppButton(text = "Mở",
    onClick = { isOpen = true })

if (isOpen) {
    Dialog(onDismissRequest = { isOpen = false }) {
        ...
    }
}

Giống hệt cách bạn đã làm ở Bài 9: một State true/false quyết định hộp thoại có hiện hay không. onDismissRequest giống (didDismiss) của Ionic: nó được gọi khi người dùng muốn đóng (bấm vùng tối hoặc nút Back). Bạn phải tự đặt isOpen = false trong đó. Nếu để trống thì hộp thoại không bao giờ đóng được.

2. Dialog: hộp thoại tự thiết kế

Dialog chỉ lo phần "khung": lớp nền tối, đặt hộp vào giữa màn hình, đóng khi bấm ra ngoài. Bên trong bạn tự vẽ gì cũng được, giống ion-modal chứa component của bạn. Lớp nền tối do Android tự vẽ, bạn không cần viết thêm gì.

Ionic / CSSCompose
.modal-backdrop (nền tối)có sẵn, Android tự vẽ
backdropDismiss="false"properties = DialogProperties(dismissOnClickOutside = false)
modal rộng hết màn hìnhDialogProperties(usePlatformDefaultWidth = false)

3. AlertDialog: hộp thoại dựng sẵn

Giống ion-alert hoặc window.confirm(): bạn chỉ điền nội dung vào các "ô" có sẵn, Material lo phần bố cục. Mỗi ô là một Composable nhỏ trong { }, giống tham số content mà bạn đã dùng trong AppToggleBox.

Ô (tham số)Chứa gì
title = { Text(...) }tiêu đề, ví dụ "Đăng xuất?"
text = { Text(...) }câu giải thích
confirmButton = { TextButton(...) }nút đồng ý, nằm bên phải
dismissButton = { TextButton(...) }nút huỷ, nằm bên trái nút đồng ý
containerColor, titleContentColor, textContentColormàu theo theme của app

TextButton là nút chỉ có chữ, không có nền, giống <ion-button fill="clear">.

4. Bottom Sheet tự làm: tự vẽ lớp nền tối

Muốn tự chọn màu và độ mờ của nền, hoặc muốn hộp trượt từ đáy lên như ion-modal có breakpoints, bạn tự vẽ bằng Box, giống cách làm modal bằng CSS thuần:

CSS 
.backdrop {
  position: fixed; inset: 0;
  background: rgba(0,0,0,.5);
}
.sheet {
  position: absolute; bottom: 0;
  border-radius: 24px 24px 0 0;
  transform: translateY(100%);
}
.open .sheet { transform: none; }
Compose 
Box(Modifier.fillMaxSize()) {   // cả trang
    AppPage { ... }             // nội dung trang
    AnimatedVisibility(showSheet) {
        Box(/* nền tối */) {
            Column(/* sheet */
                Modifier.align(
                    Alignment.BottomCenter)
                ...
            )
        }
    }
}

Nhớ lại Bài 8: con viết sau trong Box nằm trên. Vì vậy nền tối phải viết sau AppPage và nằm ngoài AppPage, nếu không nó sẽ bị cuộn theo trang. Có 3 điều Dialog làm sẵn mà khi tự làm bạn phải tự lo:

  • Bấm vùng tối thì đóng: thêm clickable vào Box nền tối.
  • Bấm trong sheet thì không đóng: sheet cũng cần một clickable { } để trống để "chặn" cú bấm, giống event.stopPropagation().
  • Nút Back của điện thoại: dùng BackHandler(enabled = showSheet) { showSheet = false }, giống bắt phím Escape trên web.

Một điểm mới: Modifier.animateEnterExit(...) chỉ dùng được bên trong AnimatedVisibility. Nó cho con có hiệu ứng riêng: nền tối chỉ mờ dần (fadeIn), còn sheet thì trượt lên (slideInVertically { it }, bắt đầu thấp hơn đúng bằng chiều cao của nó, giống translateY(100%)).

5. Nhiệm vụ

Bước 1: trang mới. Tạo ModalPage.kt, route "modal", và thêm link từ TemplatePage. Ở đầu hàm, khai báo 3 State: showDialog, showAlert, showSheet. Trang có một đoạn chữ dài (để thấy nền tối phủ lên chữ) và 3 nút AppButton.

Bước 2: Dialog. Code mẫu (đã build thử, chạy được). Đặt ngoài AppPage { }, ở cuối hàm:

if (showDialog) {
    Dialog(onDismissRequest = { showDialog = false }) {
        Column(
            modifier = Modifier
                .fillMaxWidth()
                .background(colors.surface, RoundedCornerShape(16.dp))
                .padding(24.dp)
        ) {
            Text("Xoá ảnh này?", style = titleMedium, color = colors.text)
            Spacer(modifier = Modifier.height(8.dp))
            Text("Ảnh sẽ bị xoá vĩnh viễn và không khôi phục được.", color = colors.text)
            Spacer(modifier = Modifier.height(20.dp))
            Row(horizontalArrangement = Arrangement.spacedBy(12.dp)) {
                AppButton(
                    text = "Huỷ",
                    onClick = { showDialog = false },
                    backgroundColor = colors.secondary,
                    modifier = Modifier.weight(1f)
                )
                AppButton(
                    text = "Xoá",
                    onClick = { showDialog = false },
                    backgroundColor = colors.danger,
                    modifier = Modifier.weight(1f)
                )
            }
        }
    }
}

Import: androidx.compose.ui.window.Dialog. Thử thêm properties = DialogProperties(dismissOnClickOutside = false) rồi bấm ra ngoài để thấy khác biệt.

Bước 3: AlertDialog. Tự viết theo bảng ở mục 3: tiêu đề "Đăng xuất?", câu "Bạn có chắc muốn đăng xuất không?", nút "Đăng xuất" và "Huỷ". Cả hai nút đều đặt showAlert = false. Nhớ truyền containerColor = colors.surface và 2 màu chữ colors.text để Dark Mode đúng màu.

Bước 4: Bottom Sheet. Đổi khung trang thành Box(Modifier.fillMaxSize()) { AppPage {...} ... } như mục 4. Phần sheet (đã build thử):

AnimatedVisibility(visible = showSheet, enter = fadeIn(), exit = fadeOut()) {
    Box( // nền tối
        modifier = Modifier
            .fillMaxSize()
            .background(Color.Black.copy(alpha = 0.5f))
            .clickable(
                interactionSource = remember { MutableInteractionSource() },
                indication = null // bỏ hiệu ứng gợn sóng khi bấm
            ) { showSheet = false }
    ) {
        Column( // sheet
            modifier = Modifier
                .align(Alignment.BottomCenter)
                .animateEnterExit(
                    enter = slideInVertically { it },
                    exit = slideOutVertically { it }
                )
                .fillMaxWidth()
                .background(colors.surface, RoundedCornerShape(topStart = 24.dp, topEnd = 24.dp))
                .clickable(
                    interactionSource = remember { MutableInteractionSource() },
                    indication = null
                ) { } // chặn cú bấm, không cho lọt xuống nền tối
                .navigationBarsPadding() // chừa chỗ cho thanh điều hướng của điện thoại
                .padding(24.dp)
        ) {
            Text("Chọn ảnh", style = titleMedium, color = colors.text)
            // tự thêm 2 dòng lựa chọn và nút Đóng
        }
    }
}

BackHandler(enabled = showSheet) { showSheet = false }

Bạn đã gặp clickable(interactionSource..., indication = null) trong TemplatePage. Import BackHandler từ androidx.activity.compose.BackHandler.

Bước 5: tách component AppDialog vào ui/components/dialog/AppDialog.kt. Hộp thoại xác nhận sẽ dùng ở rất nhiều màn hình (xoá, đăng xuất, huỷ đơn), nên đây là component nên có cho team:

@Composable
fun AppDialog(
    title: String,
    message: String,
    confirmText: String,
    onConfirm: () -> Unit,  // bấm nút đồng ý thì làm gì
    onDismiss: () -> Unit,  // bấm Huỷ, vùng tối hoặc Back
    dismissText: String = "Huỷ",
    confirmColor: Color = colors.primary, // truyền colors.danger cho hành động nguy hiểm
) {
    // Dialog + Column như Bước 2
}

() -> Unit nghĩa là "một đoạn code sẽ chạy khi bấm", giống truyền một hàm vào onclick. AppButton của bạn cũng có onClick: () -> Unit. Lưu ý: AppDialog không tự chứa if (show), trang nào dùng thì tự viết if bên ngoài. Sau đó thay Bước 2 bằng AppDialog.

Bước 6: kiểm tra. Với cả 3 hộp thoại, thử: bấm vào vùng tối, bấm vào bên trong hộp, bấm nút Back của điện thoại, và chuyển Light/Dark.

Material còn có ModalBottomSheet dựng sẵn, có thể kéo bằng tay để đóng như ion-modal. Component này vẫn đang ở dạng thử nghiệm (cần thêm @OptIn). Muốn thử thì hãy hỏi agent. Toast (Snackbar) sẽ học ở Bài 19. Báo "xong bài 10" khi xong.

6. Kiểm tra nhanh

1. Bạn viết Dialog(onDismissRequest = { }) để trống. Chuyện gì xảy ra khi bấm vùng tối?
2. Muốn người dùng bắt buộc bấm nút, bấm ra ngoài không đóng (giống backdropDismiss="false")?
3. Trong Bottom Sheet tự làm, vì sao sheet cần một clickable { } để trống?
4. Nút Back của điện thoại tương đương phím nào trên web khi đang mở modal?
5. (Ôn bài 9) Nền tối mờ dần, còn sheet trượt lên. Cái gì cho phép con có hiệu ứng riêng?
