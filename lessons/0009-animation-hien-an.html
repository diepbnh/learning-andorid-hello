Animation: chữ hiện dần, bấm nút để hiện/ẩn, toggleClass có transition

Bài 8: xong. Bạn đã thêm surface vào theme. Nếu chưa sửa ColorAlPhaBox (nền mờ, chữ rõ) thì sửa luôn nhé. Theo yêu cầu của bạn, bài này học animation trước. Card và Badge chuyển sang Bài 11.

Kết quả mong đợi

Một trang Animation có 3 phần. Hình dưới đây bấm được: bạn thử bấm nút và bấm vào ô để thấy chuyển động mà app cần đạt được.

Chú ý khi so sánh: (1) Khi mở trang, dòng chào trượt từ dưới lên và hiện dần trong 0.8 giây, dòng thứ hai chạy chậm hơn 0.3 giây. (2) Bấm nút thì ô nội dung mở ra mượt, các phần bên dưới bị đẩy xuống từ từ, và chữ trên nút đổi thành "Ẩn nội dung". (3) Bấm vào ô cuối thì nền đổi dần sang colors.primary, chữ thành trắng và góc bo tròn hơn. Bấm lần nữa thì trở về như cũ.

1. Ý tưởng chính: animation chạy khi State đổi

Web 
.box { transition: background .3s; }
.box.active { background: blue; }

// JS: đổi class → CSS tự chạy transition
box.classList.toggle('active');
Compose 
var isActive by remember {
    mutableStateOf(false)
}

// đổi State → Compose vẽ lại,
// animate...AsState tự chạy chuyển động
isActive = !isActive

Bạn đã dùng remember { mutableStateOf(...) } ở Bài 3 và Bài 5 để nhớ chữ người dùng gõ. Nó giống một biến JS có thêm "phép thuật": mỗi lần đổi giá trị, màn hình tự vẽ lại. Trong Compose, State đóng vai trò của class. Bạn không đi "thêm/bớt class" mà chỉ đổi true ↔ false, rồi viết giao diện theo giá trị đó.

!isActive nghĩa là "ngược lại của isActive": đang true thành false và ngược lại. Đây chính là toggle.

2. Hiện/ẩn có transition → AnimatedVisibility

Web (jQuery) 
$('.btn').click(() => {
  $('.content').slideToggle(300);
});
Compose 
AnimatedVisibility(
    visible = isOpen,
    enter = fadeIn() + expandVertically(),
    exit = fadeOut() + shrinkVertically()
) {
    // nội dung bị ẩn/hiện
}

visible = true thì nội dung chạy hiệu ứng enter để hiện ra. false thì chạy exit rồi biến mất hẳn (giống display: none, không chiếm chỗ). Dấu + ghép nhiều hiệu ứng chạy cùng lúc, giống khai báo nhiều thuộc tính trong một transition.

CSSHiện (enter)Ẩn (exit)
opacity 0 ↔ 1fadeIn()fadeOut()
height 0 ↔ autoexpandVertically()shrinkVertically()
transform: translateY(...)slideInVertically()slideOutVertically()
transform: scale(...)scaleIn()scaleOut()

Một điểm hay hơn CSS: trên web, height: auto không chạy transition được. Trong Compose, expandVertically tự đo chiều cao nội dung, bạn không cần làm gì thêm.

3. toggleClass + transition → animate...AsState

val bgColor by animateColorAsState(
    targetValue = if (isActive) colors.primary else colors.surface,
    animationSpec = tween(durationMillis = 300), // transition-duration: 300ms
    label = "bgColor"
)

Đọc là: "màu nền muốn tới (targetValue) là primary khi active, là surface khi không". Khi isActive đổi, bgColor không nhảy ngay sang màu mới mà chuyển dần trong 300ms. Sau đó bạn dùng bgColor như một màu bình thường: .background(bgColor). label chỉ là tên để công cụ debug của Android Studio hiển thị.

Muốn transition thuộc tínhDùng
màu: background-color, coloranimateColorAsState
kích thước: border-radius, width, paddinganimateDpAsState
số thường: opacity, scale, rotateanimateFloatAsState
CSSCompose animationSpec
transition: 300ms easetween(durationMillis = 300)
transition-delay: 300mstween(300, delayMillis = 300)
hiệu ứng nảy (bounce)spring(dampingRatio = Spring.DampingRatioMediumBouncy)

4. Chữ hiện dần khi mở trang → LaunchedEffect

CSS 
.hello {
  animation: fadeUp .8s;
}
.hello-sub {
  animation: fadeUp .8s .3s both;
}
Compose 
var showTitle by remember { mutableStateOf(false) }
LaunchedEffect(Unit) { showTitle = true }

AnimatedVisibility(
    visible = showTitle,
    enter = fadeIn(tween(800)) +
        slideInVertically(tween(800)) { it / 2 }
) { Text("Xin chào, Hong Diep!") }

Mẹo: bắt đầu với showTitle = false (đang ẩn), rồi ngay khi trang hiện ra thì đổi thành true. AnimatedVisibility thấy State đổi nên chạy hiệu ứng hiện.

LaunchedEffect(Unit) { ... } giống window.onload: đoạn code trong ngoặc chạy một lần khi Composable xuất hiện lần đầu. Chữ Unit nghĩa là "không phụ thuộc gì, chỉ chạy một lần". Đừng đổi State trực tiếp trong thân Composable, vì làm vậy sẽ vẽ lại mãi không dừng.

{ it / 2 } là "bắt đầu từ vị trí thấp hơn nửa chiều cao của chữ", giống translateY(50%). it là chiều cao mà Compose đưa vào cho bạn.

5. Nhiệm vụ

Bước 1: trang mới. Tạo AnimationPage.kt, route "animation", dùng AppPage, và thêm link từ TemplatePage.

Bước 2: chữ hiện dần. Làm 2 dòng như mục 4. Dòng thứ hai dùng fadeIn(tween(800, delayMillis = 300)) để chạy chậm hơn. Cả hai dòng dùng chung một showTitle.

Bước 3: nút hiện/ẩn. Code mẫu (đã build thử, chạy được):

var isOpen by remember { mutableStateOf(false) }

AppButton(
    text = if (isOpen) "Ẩn nội dung" else "Xem nội dung",
    onClick = { isOpen = !isOpen } // toggle
)
AnimatedVisibility(
    visible = isOpen,
    enter = fadeIn() + expandVertically(),
    exit = fadeOut() + shrinkVertically()
) {
    Box(
        modifier = Modifier
            .fillMaxWidth()
            .padding(top = 8.dp)
            .background(colors.surface, RoundedCornerShape(12.dp))
            .padding(16.dp)
    ) {
        Text("Đây là nội dung ẩn. Bấm nút lần nữa để ẩn đi.", color = colors.text)
    }
}

Thử thay expandVertically() bằng scaleIn() hoặc slideInVertically() để thấy khác biệt.

Bước 4: ô toggle. Tự viết theo mục 3. Ô có isActive riêng, 3 giá trị chuyển động: bgColor (surface ↔ primary), textColor (text ↔ white), radius (8dp ↔ 28dp, dùng animateDpAsState). Thứ tự Modifier gợi ý: .clip(RoundedCornerShape(radius)).background(bgColor).clickable { isActive = !isActive }.padding(16.dp). Chữ trong ô đổi theo trạng thái: if (isActive) "Đang bật" else "Đang tắt".

Bước 5: kiểm tra. Build, chạy, thử cả Light và Dark. Muốn xem lại hiệu ứng chữ thì bấm Back rồi vào lại trang. Thử đổi tween(300) thành tween(2000) để quan sát chậm, rồi thử spring(dampingRatio = Spring.DampingRatioMediumBouncy) để thấy hiệu ứng nảy.

Khi viết, Android Studio sẽ hỏi import. Các import cần có nằm trong androidx.compose.animation (ví dụ AnimatedVisibility, fadeIn, animateColorAsState) và androidx.compose.animation.core (tween, animateDpAsState).
