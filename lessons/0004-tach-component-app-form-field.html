Bài 4 / Mission: Jetpack Compose UI cho Designer

Tách code lặp thành component của riêng bạn — AppFormField

Bài 3: xong, build thành công. Không chỉ dựng được SignUpPage, bạn còn tự thêm tham số mới visualTransformation cho AppTextField để ẩn mật khẩu, có giá trị mặc định nên các chỗ gọi cũ không bị hỏng. Đây là bước từ dùng component sang thiết kế component. Bạn còn tự làm TemplatePage, một trang trưng bày component (giống một trang component trong Figma). Bài này sẽ dùng tiếp trang đó.

0. Sửa nhanh hai điểm từ bài 3

a) Quay lại Login. navController.navigate("login") đẩy thêm một màn Login mới lên trên cùng, nên bấm nút Back của máy sẽ quay lại Sign Up. Muốn "quay lại" thật sự thì lấy màn hiện tại ra:

Tư duy web 
history.pushState(...) // đi tới
history.back()         // quay lại
Compose 
navController.navigate("sign_up")
navController.popBackStack()

Đổi dòng navigate("login") trong SignUpPage.kt (và cả trong ResetPasswordPage.kt) thành navController.popBackStack() (Back stack — Android Developers).

b) value không nên có giá trị mặc định. Trong AppTextField bạn viết value: String = "". Nếu sau này quên truyền value, app vẫn build được nhưng gõ vào không hiện chữ, một lỗi rất khó tìm. Bỏ = "" đi thì Kotlin sẽ bắt buộc nơi gọi phải truyền value, và báo lỗi ngay khi build nếu quên.

1. Vấn đề: một khối code lặp 3 lần

Trong SignUpPage.kt, khối này xuất hiện 3 lần, chỉ khác chữ:

Text(text = "Password:", fontWeight = FontWeight.Medium,
     modifier = Modifier.padding(bottom = 10.dp))
AppTextField(value = ..., onValueChange = ..., placeholder = "...",
             visualTransformation = PasswordVisualTransformation())

Với Designer, đây là lúc bạn sẽ tạo component trong Figma: gom label và ô nhập thành một "Form field", những chỗ khác nhau (chữ label, có ẩn ký tự không) trở thành property. Trong Compose thì property chính là tham số của một Custom Composable Component.

2. Khái niệm mới: if … else cho ra một giá trị

Bạn muốn một property kiểu bật/tắt (giống Boolean property trong Figma): isPassword. Nhưng AppTextField không nhận true/false, nó cần một VisualTransformation. Trong Kotlin, if … else có thể trả về một giá trị để gán thẳng vào tham số:

visualTransformation = if (isPassword) PasswordVisualTransformation()
                       else VisualTransformation.None

Đọc là: "nếu isPassword đúng thì dùng kiểu ẩn ký tự, còn không thì để nguyên". Khi dùng if như một giá trị thì bắt buộc phải có else, vì trường hợp nào cũng phải ra một kết quả (If expression — kotlinlang.org).

3. Nhiệm vụ

Bước 1. Tạo file ui/components/textfield/AppFormField.kt. Phần khung đã có sẵn, bạn chỉ cần viết phần thân:

@Composable
fun AppFormField(
    label: String,
    value: String,
    onValueChange: (String) -> Unit,
    modifier: Modifier = Modifier,
    placeholder: String = "",
    isPassword: Boolean = false,
) {
    Column(modifier = modifier) {
        // 1. Text hiển thị label (copy style từ SignUpPage)
        // 2. AppTextField: truyền value, onValueChange, placeholder,
        //    visualTransformation = if (isPassword) ... else ...
    }
}

Vì sao có tham số modifier? Để nơi gọi tự quyết định kích thước và khoảng cách của component, giống việc đặt constraint cho một instance trong Figma. Đây là quy ước chính thức cho mọi component Compose (Compose component API guidelines). Nhớ truyền modifier vào Column. Đừng dùng Modifier mới ở đó, nếu không thì những gì nơi gọi truyền vào sẽ bị bỏ qua.

Bước 2. Trong SignUpPage.kt, thay 3 khối lặp bằng 3 lời gọi, ví dụ:

AppFormField(
    label = "Password:",
    value = password.value,
    onValueChange = { password.value = it },
    placeholder = "Enter password",
    isPassword = true,
)

Bước 3. Thêm một AppFormField vào TemplatePage. Từ giờ, mỗi component mới đều "có mặt" trong trang trưng bày của bạn.

Bước 4. Chạy ./gradlew compileDebugKotlin rồi mở app xem thử. Giao diện Sign Up phải trông y như cũ, chỉ có code là gọn hơn. Đó là dấu hiệu tách component đúng.

Kẹt ở đâu, ví dụ không biết import gì, hay build báo lỗi đỏ, thì cứ dán lỗi và hỏi agent. Khi xong, báo "xong bài 4" để được review code.
