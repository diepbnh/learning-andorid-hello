AppCard: một component, 3 kiểu Filled / Elevated / Outlined

Ý tưởng của bạn: 3 kiểu card giống nhau ở padding, góc bo và nền surface, chỉ khác nhau ở chỗ có bóng đổ hay không và có viền hay không. Đây chính là cách thiết kế component đúng: phần giống nhau viết một lần, phần khác nhau thì chọn bằng tham số. Bạn đã làm việc này ở Bài 2 với biến thể của AppButton, giờ áp dụng cho card.

Hiện bạn đang viết Card(...) ở 4 chỗ (3 chỗ trong CardPage, 1 chỗ trong ToggleButtonPage), chỗ nào cũng lặp lại shape, shadow và CardDefaults.cardColors(...). Sau bài này, mỗi chỗ chỉ còn một dòng AppCard(...).

Kết quả mong đợi

Trang Card có 3 card xếp dọc, mỗi card một kiểu, cùng padding 16dp, bo góc 16dp và nền surface.

Chú ý khi so sánh: cả 3 card có cùng kích thước chữ, padding và góc bo. Chỉ card thứ 2 có bóng, chỉ card thứ 3 có viền. Ở Dark Mode, viền phải thấy được (sáng hơn nền card). Vì vậy bài này thêm màu border vào theme, vì colors.light ở Dark Mode gần trùng màu với surface.

Compose 
enum class AppCardVariant {
    Filled, Elevated, Outlined
}

AppCard(variant = AppCardVariant.Outlined) {
    Text("Sapa mùa lúa chín")
}

enum class giống danh sách các class modifier --filled, --elevated, --outlined. Bạn chỉ được chọn một trong số đó, gõ sai tên thì build báo lỗi ngay.

2. Chọn bóng và viền bằng when

val shadowModifier = when (variant) {
    AppCardVariant.Elevated -> Modifier.shadow(elevation = 6.dp, shape = shape)
    AppCardVariant.Filled, AppCardVariant.Outlined -> Modifier // không thêm gì
}
val border = when (variant) {
    AppCardVariant.Outlined -> BorderStroke(1.dp, colors.border)
    AppCardVariant.Filled, AppCardVariant.Elevated -> null    // không có viền
}
  • when bạn đã học ở Bài 2. Dấu phẩy Filled, Outlined -> nghĩa là "Filled hoặc Outlined thì làm giống nhau".
  • Modifier đứng một mình là "Modifier rỗng", không làm gì cả. Bạn đã dùng nó trong .then(if ... else Modifier) ở AppAvatar và AppPage.
  • null nghĩa là "không có gì", giống border: none. Tham số border của Card nhận null để hiểu là không vẽ viền.
  • BorderStroke(1.dp, màu) giống 1px solid màu.

3. Phần nội dung: slot content

Giống AppDialog của bạn, AppCard nhận nội dung từ bên ngoài. Điểm mới là ColumnScope.(): nội dung được đặt sẵn trong một Column có padding, nên trang dùng card chỉ cần viết các dòng con, và vẫn dùng được Modifier.align(...) như khi viết trong Column.

content: @Composable ColumnScope.() -> Unit
...
Column(modifier = Modifier.padding(contentPadding)) {
    content() // vẽ nội dung mà trang truyền vào, giống <slot>
}

4. Nhiệm vụ

Bước 1: thêm màu border vào theme. Đây là màu viền dùng chung cho cả app (card, ô nhập, đường kẻ). Thêm vào đủ 4 chỗ trong Color.kt như bạn đã làm với surface: Light 0xFFDFE4E8, Dark 0xFF3A3F47.

Bước 2: tạo ui/components/card/AppCardVariant.kt:

enum class AppCardVariant {
    Filled,   // không bóng, không viền
    Elevated, // có bóng đổ
    Outlined, // có viền
}

Bước 3: tạo ui/components/card/AppCard.kt. Code mẫu (đã build thử, chạy được):

@Composable
fun AppCard(
    modifier: Modifier = Modifier,
    variant: AppCardVariant = AppCardVariant.Elevated, // kiểu mặc định
    cornerRadius: Dp = 16.dp,   // border-radius
    contentPadding: Dp = 16.dp, // padding bên trong
    content: @Composable ColumnScope.() -> Unit
) {
    val shape = RoundedCornerShape(cornerRadius)

    // phần KHÁC nhau
    val shadowModifier = when (variant) {
        AppCardVariant.Elevated -> Modifier.shadow(elevation = 6.dp, shape = shape)
        AppCardVariant.Filled, AppCardVariant.Outlined -> Modifier
    }
    val border = when (variant) {
        AppCardVariant.Outlined -> BorderStroke(1.dp, colors.border)
        AppCardVariant.Filled, AppCardVariant.Elevated -> null
    }

    // phần GIỐNG nhau
    Card(
        modifier = modifier
            .fillMaxWidth()
            .then(shadowModifier), // bóng phải đứng trước nền (Card tự vẽ nền bên trong)
        shape = shape,
        border = border,
        colors = CardDefaults.cardColors(
            containerColor = colors.surface,
            contentColor = colors.text
        )
    ) {
        Column(modifier = Modifier.padding(contentPadding)) {
            content()
        }
    }
}

Muốn card Elevated dùng bóng kiểu Figma của bạn? Thay Modifier.shadow(...) bằng Modifier.boxShadow(...) trong Shadow.kt. Chỉ cần sửa một chỗ này, mọi card trong app sẽ đổi theo.

Bước 4: trưng bày. Trong CardPage, thêm 3 AppCard như hình kết quả, mỗi card có một tiêu đề in đậm (fontWeight = FontWeight.Bold) và một dòng mô tả. Theo quy ước của project, thêm một AppCard nhỏ vào TemplatePage.

Bước 5: thay code cũ. Đổi 4 chỗ Card(...) cũ (ShadowCard, ShadowCard2, ShadowCard3 và card trong ToggleButtonPage) sang AppCard. ShadowCard2 (bóng màu xanh) và ShadowCard3 (bóng custom màu đỏ) có kiểu riêng: hãy dùng variant = AppCardVariant.Filled rồi tự thêm bóng qua modifier, ví dụ AppCard(variant = AppCardVariant.Filled, modifier = Modifier.boxShadow(...)) { ... }. Đây là lý do mọi component nên có tham số modifier: cho phép "ghi đè" từ bên ngoài, giống thêm một class riêng bên cạnh .card.

Bước 6: kiểm tra. Build, chạy, chuyển Light/Dark. Viền của card Outlined phải thấy được ở cả hai mode.

Muốn card bấm được (giống <ion-card button>, có hiệu ứng gợn sóng khi chạm)? Có thể thêm tham số onClick. Cách này cần một khái niệm mới là kiểu "có thể rỗng" ((() -> Unit)?), hãy hỏi agent khi bạn muốn thử. Badge và đường kẻ <hr> sẽ học cùng thanh menu dưới ở Bài 16. Báo "xong bài 11" khi xong.
