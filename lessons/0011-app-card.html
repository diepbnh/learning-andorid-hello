AppCard: một component, bật/tắt bóng và viền bằng true / false

Ý tưởng của bạn: các card giống nhau ở padding, góc bo và nền backgroundCard, chỉ khác nhau ở chỗ có bóng đổ hay không và có viền hay không. Vì vậy AppCard chỉ cần 2 công tắc: hasShadow và hasBorder. Bật cái nào thì có cái đó. Phần giống nhau viết một lần, phần khác nhau thì chọn bằng tham số.

Hiện bạn đang viết Card(...) ở 4 chỗ (3 chỗ trong CardPage, 1 chỗ trong ToggleButtonPage), chỗ nào cũng lặp lại shape, shadow và CardDefaults.cardColors(...). Sau bài này, mỗi chỗ chỉ còn một dòng AppCard(...).

Kết quả mong đợi

Trang Card có 4 card xếp dọc, ứng với 4 tổ hợp bật/tắt, cùng padding 16dp, bo góc 16dp và nền backgroundCard.

Chú ý khi so sánh: cả 4 card có cùng kích thước chữ, padding và góc bo. Card 2 và 4 có bóng, card 3 và 4 có viền. Viền dùng màu colors.light có sẵn trong theme, không cần thêm màu mới. Ở Dark Mode, light (#22262c) khá gần nền card (#1E2228) nên viền sẽ rất mờ: hãy tự kiểm tra ở Bước 4.

Mỗi Boolean giống một class CSS: gắn card--shadow thì có bóng, gắn thêm card--border thì có thêm viền. Hai công tắc độc lập với nhau nên bật cùng lúc cũng được.

2. Bật/tắt bằng if ... else

val shadowModifier = if (hasShadow) Modifier.shadow(elevation = 6.dp, shape = shape) else Modifier
val border = if (hasBorder) BorderStroke(1.dp, colors.light) else null
  • Trong Kotlin, if ... else trả về giá trị, giống toán tử 3 ngôi a ? b : c trong JavaScript.
  • Modifier đứng một mình là "Modifier rỗng", không làm gì cả. Bạn đã dùng nó trong .then(if ... else Modifier) ở AppAvatar và AppPage.
  • null nghĩa là "không có gì", giống border: none. Tham số border của Card nhận null để hiểu là không vẽ viền.
  • BorderStroke(1.dp, màu) giống 1px solid màu.
  • Cả hai mặc định là false, nên AppCard { } không truyền gì sẽ ra card trơn.

3. Phần nội dung: slot content

Giống AppDialog của bạn, AppCard nhận nội dung từ bên ngoài. Điểm mới là ColumnScope.(): nội dung được đặt sẵn trong một Column có padding, nên trang dùng card chỉ cần viết các dòng con, và vẫn dùng được Modifier.align(...) như khi viết trong Column.

content: @Composable ColumnScope.() -> Unit
...
Column(modifier = Modifier.padding(contentPadding)) {
    content() // vẽ nội dung mà trang truyền vào, giống <slot>
}

4. Nhiệm vụ

Bước 1: tạo ui/components/card/AppCard.kt. Mọi thứ đều truyền được từ ngoài vào, nhưng đều có giá trị mặc định, nên lúc dùng bình thường không cần truyền gì:

@Composable
fun AppCard(
    modifier: Modifier = Modifier,
    // bật / tắt
    hasShadow: Boolean = false, // true = có bóng đổ
    hasBorder: Boolean = false, // true = có viền
    // màu
    backgroundColor: Color = colors.backgroundCard, // màu nền card
    textColor: Color = colors.text,                 // màu chữ bên trong
    borderColor: Color = colors.light,              // màu viền
    shadowColor: Color = Color.Black,               // màu bóng
    // kích thước
    borderWidth: Dp = 1.dp,       // độ dày viền
    shadowElevation: Dp = 6.dp,   // độ cao bóng (càng lớn bóng càng rộng)
    cornerRadius: Dp = 16.dp,     // border-radius
    contentPadding: Dp = 16.dp,   // padding bên trong
    content: @Composable ColumnScope.() -> Unit
) {
    val shape = RoundedCornerShape(cornerRadius)

    // phần KHÁC nhau: bật cái nào thì có cái đó
    val shadowModifier = if (hasShadow) {
        Modifier.shadow(
            elevation = shadowElevation,
            shape = shape,
            ambientColor = shadowColor, // viền mờ đều xung quanh
            spotColor = shadowColor     // bóng đậm phía dưới
        )
    } else {
        Modifier
    }
    val border = if (hasBorder) BorderStroke(borderWidth, borderColor) else null

    // phần GIỐNG nhau
    Card(
        modifier = modifier
            .fillMaxWidth()
            .then(shadowModifier), // bóng phải đứng trước nền (Card tự vẽ nền bên trong)
        shape = shape,
        border = border,
        colors = CardDefaults.cardColors(
            containerColor = backgroundColor,
            contentColor = textColor
        )
    ) {
        Column(modifier = Modifier.padding(contentPadding)) {
            content()
        }
    }
}
  • Giá trị mặc định được viết ngay sau dấu = của tham số, giống function f(color = "red") trong JavaScript. Mặc định có thể là màu của theme như colors.light, nên đổi Light/Dark thì mặc định cũng đổi theo.
  • Color.Black là màu bóng mặc định của Modifier.shadow, nên không truyền shadowColor thì bóng giống hệt trước.
  • Muốn bóng kiểu Figma (lệch x, y, blur)? Card đó dùng Modifier.boxShadow(...) qua tham số modifier, như ShadowCard3 ở Bước 3.

Bước 2: trưng bày. Trong CardPage, thêm 4 AppCard như hình kết quả, mỗi card có một tiêu đề in đậm (fontWeight = FontWeight.Bold) và một dòng mô tả. Theo quy ước của project, thêm một AppCard nhỏ vào TemplatePage.

Bước 3: thay code cũ. Đổi 4 chỗ Card(...) cũ (ShadowCard, ShadowCard2, ShadowCard3 và card trong ToggleButtonPage) sang AppCard. ShadowCard và card trong ToggleButtonPage dùng hasShadow = true. ShadowCard2 (bóng màu xanh) giờ chỉ cần hasShadow = true, shadowColor = colors.primary. ShadowCard3 (bóng custom lệch x, y màu đỏ) không dùng được shadow thường: để hasShadow mặc định false rồi tự thêm bóng qua modifier, ví dụ AppCard(modifier = Modifier.boxShadow(...)) { ... }. Đây là lý do mọi component nên có tham số modifier: cho phép "ghi đè" từ bên ngoài, giống thêm một class riêng bên cạnh .card.

Bước 4: kiểm tra. Build, chạy, chuyển Light/Dark. Viền của card 3 và 4 phải thấy được ở cả hai mode. Nếu ở Dark Mode viền quá mờ, lúc đó mới cân nhắc thêm một màu viền riêng vào theme.

Muốn card bấm được (giống <ion-card button>, có hiệu ứng gợn sóng khi chạm)? Có thể thêm tham số onClick. Cách này cần một khái niệm mới là kiểu "có thể rỗng" ((() -> Unit)?), hãy hỏi agent khi bạn muốn thử. Badge và đường kẻ <hr> sẽ học cùng thanh menu dưới ở Bài 16. Báo "xong bài 11" khi xong.
