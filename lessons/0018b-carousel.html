Carousel: vuốt qua lại giữa các slide, giống Swiper và ion-slides

Bài 18 là thanh kéo Slider. Bài này là loại "slider" thứ hai mà web hay gọi: carousel, một dải ảnh hoặc thẻ nằm ngang, vuốt để xem cái tiếp theo. Compose gọi nó là Pager (lật trang).

Bài chia 2 phần: Phần A viết thẳng trong trang 3 carousel (ảnh rộng hết, ảnh ló hai bên, thẻ text), có chấm chỉ trang và tự chạy. Phần B gom lại thành AppCarousel dùng được cho cả ảnh lẫn text.

Kết quả mong đợi

Trang Carousel (mở từ side menu) có 3 phần. Featured cars: mỗi lần một ảnh rộng hết, tự chuyển sau 3 giây. Gallery: ảnh ở giữa, hai bên ló ra một phần ảnh trước và sau. Car care tips: thẻ chữ cũng ló hai bên. Dưới mỗi carousel có hàng chấm, chấm của trang hiện tại dài ra và đổi màu. Hình vuốt được (kéo chuột sang trái/phải) và bấm chấm được.

Chú ý khi so sánh: ảnh cao 180dp, bo góc 16dp, cắt vừa khung (ContentScale.Crop). Ở Gallery và Car care tips, slide ở giữa, hai bên ló ra khoảng 32dp, giữa các slide cách 12dp. Chấm cao 8dp: chấm thường rộng 8dp màu colors.light, chấm hiện tại rộng 20dp màu colors.primary. Thẻ tip là AppCard mặc định (không bóng), các thẻ cao bằng nhau. Chỉ Featured cars tự chạy; slide cuối tự quay về slide đầu.

3. Phần A: viết thẳng trong trang

A1. Tạo trang CarouselPage.kt, route "carousel", khung giống SliderPage ở Bài 18 (AppDrawer → AppPage → AppTopBar("Carousel")). Thêm route vào MainActivity.kt và MenuItem("Carousel", "carousel", Icons.Default.Settings) vào AppDrawer.kt.

A2. Featured cars: mỗi lần một ảnh. Ảnh lấy từ res/drawable có sẵn trong project:

val cars = listOf(R.drawable.car01, R.drawable.car02, R.drawable.car03, R.drawable.car04)
val pagerState = rememberPagerState(pageCount = { cars.size })

Text(text = "Featured cars", fontWeight = FontWeight.SemiBold)
HorizontalPager(state = pagerState) { page ->   // page = index of the slide being drawn
    Image(
        painter = painterResource(cars[page]),
        contentDescription = null,
        contentScale = ContentScale.Crop,           // object-fit: cover
        modifier = Modifier
            .fillMaxWidth()
            .height(180.dp)
            .clip(RoundedCornerShape(16.dp))
    )
}

Chạy thử: vuốt ngang được, thả tay thì tự dừng đúng giữa một ảnh.

A3. Hàng chấm (dots). Đặt ngay dưới HorizontalPager:

Row(
    modifier = Modifier.fillMaxWidth().padding(top = 12.dp),
    horizontalArrangement = Arrangement.spacedBy(6.dp, Alignment.CenterHorizontally) // gap + center
) {
    repeat(pagerState.pageCount) { index ->
        val isCurrent = index == pagerState.currentPage
        Box(
            modifier = Modifier
                .size(width = if (isCurrent) 20.dp else 8.dp, height = 8.dp) // current dot is longer
                .background(if (isCurrent) colors.primary else colors.light, CircleShape)
        )
    }
}

CircleShape trên một hình chữ nhật 20×8 sẽ thành viên thuốc (pill), giống border-radius: 999px.

A4. Tự chạy sau 3 giây. Thêm ngay sau dòng rememberPagerState:

LaunchedEffect(pagerState.settledPage) {      // restart the timer every time the page changes
    delay(3000)
    val next = (pagerState.currentPage + 1) % pagerState.pageCount // last → back to 0
    pagerState.animateScrollToPage(next)         // slide with animation
}

LaunchedEffect bạn đã gặp ở Bài 9. Khi giá trị trong ngoặc đổi, nó huỷ lần chạy cũ và chạy lại từ đầu. settledPage là trang đã dừng hẳn. Nhờ vậy, khi người dùng tự vuốt sang trang khác, đồng hồ 3 giây đếm lại từ đầu, carousel không giật sang trang khác ngay sau khi vuốt. delay cần import kotlinx.coroutines.delay.

A5. Gallery: ảnh ló hai bên. Chép A2 + A3 thành carousel thứ hai, với pagerState riêng (đặt tên galleryState), rồi thêm 2 tham số cho HorizontalPager:

HorizontalPager(
    state = galleryState,
    contentPadding = PaddingValues(horizontal = 32.dp), // show 32dp of the previous / next slide
    pageSpacing = 12.dp                                 // gap between slides
) { page -> ... }

A6. Car care tips: thẻ text. Mỗi tip có 2 phần (tiêu đề + mô tả) nên gom bằng data class, giống MenuItem ở Bài 15. Đặt data class bên ngoài hàm CarouselPage:

data class Tip(val title: String, val body: String)

// inside CarouselPage:
val tips = listOf(
    Tip("Check tire pressure", "Once a month, when the tires are cold."),
    Tip("Change engine oil", "Every 5,000 km or 6 months."),
    Tip("Test the battery", "Before long trips and every winter."),
)
val tipState = rememberPagerState(pageCount = { tips.size })

HorizontalPager(
    state = tipState,
    contentPadding = PaddingValues(horizontal = 32.dp),
    pageSpacing = 12.dp
) { page ->
    AppCard(modifier = Modifier.fillMaxWidth().height(100.dp)) { // same height for all cards
        Text(text = tips[page].title, fontWeight = FontWeight.SemiBold)
        Text(text = tips[page].body)
    }
}

Vì sao height(100.dp)? Mô tả dài ngắn khác nhau, nếu để thẻ tự cao theo chữ thì khi vuốt, chiều cao carousel nhảy lên xuống. Vì sao không dùng hasShadow = true? Pager cắt mọi thứ vẽ ra ngoài khung của nó, nên bóng ở mép dưới bị cắt mất (giống lỗi bóng bị cắt bạn từng gặp ở bài animation). Hàng chấm bạn tự thêm.

Quan sát trước khi sang Phần B: 3 carousel giống nhau đến 80%: pagerState, hàng chấm, padding. Chỉ khác nội dung mỗi slide (ảnh hay thẻ) và có ló hai bên / tự chạy hay không. Phần B gom phần giống nhau, phần khác thì để trang truyền vào.

4. Phần B: component AppCarousel

Bước 1: tạo ui/components/carousel/AppCarousel.kt. Code mẫu (đã build thử trên project, chạy được):

@Composable
fun AppCarousel(
    pageCount: Int,                         // how many slides
    modifier: Modifier = Modifier,
    peek: Dp = 0.dp,                        // how much of the previous / next slide to show
    autoPlay: Boolean = false,              // move to the next slide by itself
    intervalMillis: Long = 3000,            // time between slides when autoPlay is on
    content: @Composable (page: Int) -> Unit // how slide number "page" looks
) {
    val pagerState = rememberPagerState(pageCount = { pageCount })

    if (autoPlay) {
        LaunchedEffect(pagerState.settledPage) {
            delay(intervalMillis)
            pagerState.animateScrollToPage((pagerState.currentPage + 1) % pageCount)
        }
    }

    Column(modifier = modifier.fillMaxWidth()) {
        // 1. Slides
        HorizontalPager(
            state = pagerState,
            contentPadding = PaddingValues(horizontal = peek),
            pageSpacing = if (peek > 0.dp) 12.dp else 0.dp
        ) { page ->
            content(page)
        }
        // 2. Dots
        Row(
            modifier = Modifier.fillMaxWidth().padding(top = 12.dp),
            horizontalArrangement = Arrangement.spacedBy(6.dp, Alignment.CenterHorizontally)
        ) {
            repeat(pageCount) { index ->
                val isCurrent = index == pagerState.currentPage
                Box(
                    modifier = Modifier
                        .size(width = if (isCurrent) 20.dp else 8.dp, height = 8.dp)
                        .background(if (isCurrent) colors.primary else colors.light, CircleShape)
                )
            }
        }
    }
}

Điểm mới: content: @Composable (page: Int) -> Unit là một slot có tham số. Slot ở AppCard hay AppBottomBar không nhận gì; slot này nhận số thứ tự trang, để trang tự vẽ slide đó. Giống hàm render trong JS: renderSlide(page). pagerState nằm bên trong component vì trang không cần biết đang ở slide nào (giống expanded của AppDropdown).

Bước 3: kiểm tra. Vuốt cả 3 carousel, chấm đổi theo. Featured cars tự chạy, đến ảnh cuối thì quay về ảnh đầu. Vuốt tay xong thì đợi đủ 3 giây mới tự chuyển. Kiểm tra Light/Dark.

Thử thách (tuỳ chọn):

  • Bấm chấm để nhảy trang. Thêm .clickable { ... } vào mỗi chấm. Vì animateScrollToPage phải chạy trong coroutine, dùng rememberCoroutineScope() + scope.launch { pagerState.animateScrollToPage(index) }, giống cách mở side menu ở Bài 15.
  • Nút mũi tên ‹ › hai bên ảnh: Icons.Default.KeyboardArrowLeft / KeyboardArrowRight (có trong icons.core), đặt trong Box chồng lên pager, cùng cách gọi scope.launch như trên.
  • Chấm dài ra mượt: dùng animateDpAsState (Bài 9) cho chiều rộng chấm.
