Bài 12: xong. AppCheckbox và AppSwitch đều giữ State ở trang (state hoisting), bấm được cả dòng, và Switch "Dark Mode" đổi theme thật. Nhớ thêm enabled = acceptTerms cho nút Save nếu bạn chưa thêm. Bài sau (Bài 14) sẽ làm header cho trang theo yêu cầu của bạn.

Kết quả mong đợi

Thêm 2 nhóm radio vào SettingPage, mỗi nhóm trong một AppCard. Chọn cỡ chữ thì đoạn chữ mẫu đổi cỡ ngay. Chọn ngôn ngữ thì câu chào đổi ngôn ngữ. Hình dưới đây bấm được.

Chú ý khi so sánh: trong mỗi nhóm luôn có đúng một ô được chọn. Chọn ô khác thì ô cũ tự bỏ chọn. Ô được chọn có vòng và chấm màu colors.primary, ô chưa chọn có vòng colors.secondary. Bấm vào chữ cũng chọn được. Cỡ chữ mẫu: Nhỏ 14sp, Vừa 18sp, Lớn 22sp.

1. Điểm khác Checkbox: cả nhóm chung một State

Ionic 
<ion-radio-group [value]="fontSize"
  (ionChange)="fontSize = $event.detail.value">
  <ion-radio value="Nhỏ">Nhỏ</ion-radio>
  <ion-radio value="Vừa">Vừa</ion-radio>
  <ion-radio value="Lớn">Lớn</ion-radio>
</ion-radio-group>
Compose 
var fontSize by remember { mutableStateOf("Vừa") }

RadioButton(
    selected = fontSize == "Nhỏ",
    onClick = { fontSize = "Nhỏ" }
)
RadioButton(
    selected = fontSize == "Vừa",
    onClick = { fontSize = "Vừa" }
)
// ... "Lớn" tương tự
Checkbox (Bài 12)Radio (bài này)
Statemỗi ô một biến true/falsecả nhóm một biến, lưu "đang chọn cái nào"
Ví dụvar agreed = falsevar fontSize = "Vừa"
Bấm vào thìđảo true ↔ falsegán giá trị của ô đó cho cả nhóm

fontSize == "Nhỏ" là một phép so sánh: kết quả là true nếu hai bên bằng nhau, ngược lại là false. Nó giống === trong JS. Mỗi RadioButton tự hỏi "giá trị của nhóm có phải là mình không?". Vì chỉ một giá trị khớp, nên luôn chỉ có một ô được chọn. Bạn không cần tự viết code "bỏ chọn ô cũ".

Cẩn thận: = (một dấu) là gán (fontSize = "Nhỏ"), còn == (hai dấu) là so sánh. Giống JS.

2. Vẽ nhiều dòng bằng forEach

Viết tay 3 RadioButton thì được, nhưng 10 lựa chọn thì sao? Bạn đã dùng forEachIndexed ở Bài 6 để vẽ các hàng của bảng. Ở đây chỉ cần forEach (không cần số thứ tự):

JS 
['Nhỏ', 'Vừa', 'Lớn'].forEach(option => {
  // vẽ một dòng cho option
});
Compose 
listOf("Nhỏ", "Vừa", "Lớn").forEach { option ->
    // vẽ một dòng cho option
}

listOf(...) là mảng (array). option -> đặt tên cho từng phần tử, giống option => trong JS.

3. Bấm cả dòng: Modifier.selectable

Giống toggleable ở Bài 12, nhưng dành cho "chọn" thay vì "bật/tắt":

Row(
    modifier = Modifier.selectable(
        selected = option == selected,
        role = Role.RadioButton,
        onClick = { onSelectedChange(option) }
    )
) {
    RadioButton(selected = option == selected, onClick = null) // Row đã lo việc bấm
    Text(option)
}

Thêm Modifier.selectableGroup() vào Column bao ngoài để trình đọc màn hình biết các dòng này là một nhóm, giống role="radiogroup" trong HTML.

4. Dùng giá trị đã chọn: when có else

val previewSize = when (fontSize) {
    "Nhỏ" -> 14.sp
    "Lớn" -> 22.sp
    else -> 18.sp   // mọi trường hợp còn lại, gồm "Vừa"
}

Text(text = "Xin chào, Hong Diep!", fontSize = previewSize)

else giống default: trong switch của JS. Khi when so với chuỗi chữ, Kotlin bắt buộc có else, vì chuỗi có vô số giá trị có thể xảy ra. Ở Bài 2, when với enum thì không cần else, vì Kotlin biết hết các giá trị của enum.

5. Nhiệm vụ

Bước 1: thử radio thô. Trong SettingPage, viết 3 RadioButton cho cỡ chữ như mục 1 để thấy chúng chạy.

Bước 2: tạo ui/components/radio/AppRadioGroup.kt. Code mẫu (đã build thử, chạy được). Bạn có thể thêm enabled, tham số màu và indication = null cho giống AppCheckbox:

@Composable
fun AppRadioGroup(
    options: List<String>,              // danh sách lựa chọn, ví dụ listOf("Nhỏ", "Vừa", "Lớn")
    selected: String,                    // trang đưa vào: đang chọn cái nào
    onSelectedChange: (String) -> Unit,  // báo cho trang biết lựa chọn mới
    modifier: Modifier = Modifier,
) {
    Column(modifier = modifier.selectableGroup()) {
        options.forEach { option ->
            Row(
                modifier = Modifier
                    .fillMaxWidth()
                    .selectable(
                        selected = option == selected,
                        role = Role.RadioButton,
                        onClick = { onSelectedChange(option) }
                    )
                    .padding(vertical = 8.dp),
                verticalAlignment = Alignment.CenterVertically
            ) {
                RadioButton(
                    selected = option == selected,
                    onClick = null, // Row đã lo việc bấm
                    colors = RadioButtonDefaults.colors(
                        selectedColor = colors.primary,
                        unselectedColor = colors.secondary
                    )
                )
                Spacer(modifier = Modifier.width(8.dp))
                Text(text = option, color = colors.text)
            }
        }
    }
}

List<String> nghĩa là "danh sách các chuỗi chữ". Phần trong < > cho biết mỗi phần tử là kiểu gì.

Bước 3: dựng 2 nhóm theo hình kết quả.

  • Thêm 2 State ở đầu SettingPage: fontSize (mặc định "Vừa") và language (mặc định "Tiếng Việt").
  • Mỗi nhóm là một AppCard chứa một AppRadioGroup.
  • Ô "Xem trước": tự viết when cho cỡ chữ như mục 4, và thêm một when nữa cho câu chào: "English" -> "Hello, Hong Diep!", còn lại là "Xin chào, Hong Diep!".

Bước 4: kiểm tra. Mỗi nhóm luôn chỉ có một ô được chọn. Bấm vào chữ cũng chọn được. Chữ xem trước đổi cỡ và đổi ngôn ngữ ngay khi chọn. Kiểm tra cả Light và Dark Mode.

Dùng chuỗi "Nhỏ", "Vừa" thì gõ sai một chữ (ví dụ "Nho") sẽ không bị báo lỗi, chỉ chạy sai. Muốn an toàn hơn thì dùng enum class FontSizeOption { Small, Medium, Large } như Bài 2.
