Bài 16: xong. AppNavBar do bạn tự thiết kế theo Figma, có công thức chuyển tab không chồng trang. AppBottomBar nhận slot nên chứa gì cũng được. Bạn để layout hiện tại, khi cần thì thêm thanh tab vào các trang còn lại sau.

Bài này quay lại Nhóm 2: Form. Dropdown giống AppRadioGroup ở Bài 13 (chọn 1 trong nhiều), chỉ khác là danh sách được gấp gọn trong một ô, bấm vào mới mở ra. Hợp khi có nhiều lựa chọn (thành phố, hãng xe, năm sinh...).

Kết quả mong đợi

Trang Booking (đặt lịch bảo dưỡng xe) có 2 dropdown: City và Car brand, cùng kiểu ô tròn như AppTextField của bạn. Ô nào được chọn thì hiện giá trị, chưa chọn thì hiện chữ mờ. Nút "Save" nằm trong AppBottomBar. Hình bấm được.

Chú ý khi so sánh: ô dropdown cao 48dp, bo tròn 30dp, nền và viền giống AppTextField. Khi mở, viền đổi sang colors.primary và mũi tên xoay ngược lên (animation). Danh sách hiện ngay dưới ô, rộng bằng ô, nền colors.backgroundCard, bo góc 16dp. Mục đang chọn có chữ colors.primary và dấu ✓. Bấm ra ngoài thì danh sách đóng.

Compose 
ExposedDropdownMenuBox(
    expanded = expanded,           // đang mở?
    onExpandedChange = { expanded = it }
) {
    // ô hiển thị giá trị (anchor)
    Row(Modifier.menuAnchor(...)) { ... }

    // danh sách xổ xuống
    ExposedDropdownMenu(
        expanded = expanded,
        onDismissRequest = { expanded = false }
    ) {
        DropdownMenuItem(...) // mỗi option
    }
}

ExposedDropdownMenuBox lo hết phần khó: đặt danh sách ngay dưới ô, cho danh sách rộng bằng ô, mở khi bấm vào ô, và đóng khi bấm ra ngoài. Bạn chỉ cần vẽ 2 thứ: cái ô và các mục trong danh sách. Đây là component "experimental", nên cần @OptIn(ExperimentalMaterial3Api::class) như AppTopBar.

2. Hai State: một ở trong, một ở ngoài

StateNằm ở đâuVì saoGiống bài nào
expanded (đang mở hay đóng)bên trong AppDropdowntrang không cần biết dropdown đang mởAppToggleButton (Bài 9)
selected (giá trị đã chọn)bên ngoài, ở trangtrang cần đọc giá trị để lưuAppRadioGroup (Bài 13)

Đây là quy tắc chung khi làm component form: trạng thái giao diện (mở/đóng, đang nhấn...) để bên trong; dữ liệu người dùng nhập/chọn thì đưa ra ngoài (state hoisting).

3. Ô hiển thị: tự vẽ theo kiểu AppTextField

Material thường dùng OutlinedTextField làm ô. Nhưng app của bạn đã có kiểu ô riêng (bo tròn 30dp), nên ta tự vẽ ô bằng Row để đồng bộ. Điều quan trọng duy nhất: ô phải có Modifier.menuAnchor(...) để Compose biết đây là "cái neo" của danh sách.

Row(
    modifier = Modifier
        .menuAnchor(ExposedDropdownMenuAnchorType.PrimaryNotEditable) // ô chỉ để bấm, không gõ chữ
        .fillMaxWidth()
        .height(48.dp)
        ...
)

PrimaryNotEditable nghĩa là ô này chỉ để bấm chọn, không gõ chữ được, giống <select>. (Nếu muốn vừa gõ vừa gợi ý, giống <datalist>, thì dùng PrimaryEditable, phần nâng cao.)

Hai hàm nhỏ mới

  • selected.ifEmpty { placeholder }: nếu selected là chuỗi rỗng thì dùng placeholder, ngược lại dùng chính nó. Giống selected || placeholder trong JS.
  • Modifier.rotate(arrowRotation): xoay mũi tên, giống transform: rotate(). Góc lấy từ animateFloatAsState (Bài 9) nên mũi tên xoay mượt.

4. Nhiệm vụ

Bước 1: tạo ui/components/dropdown/AppDropdown.kt. Code mẫu (đã build thử, chạy được):

@OptIn(ExperimentalMaterial3Api::class)
@Composable
fun AppDropdown(
    options: List<String>,              // list of choices
    selected: String,                    // current value, "" = nothing chosen yet
    onSelectedChange: (String) -> Unit,  // tell the page the new value
    modifier: Modifier = Modifier,
    placeholder: String = "Select...",
) {
    var expanded by remember { mutableStateOf(false) } // open/closed, UI-only state
    val arrowRotation by animateFloatAsState(
        targetValue = if (expanded) 180f else 0f,
        label = "arrowRotation"
    )
    val shape = RoundedCornerShape(30.dp)

    ExposedDropdownMenuBox(
        expanded = expanded,
        onExpandedChange = { expanded = it },
        modifier = modifier
    ) {
        // 1. The field (same look as AppTextField)
        Row(
            modifier = Modifier
                .menuAnchor(ExposedDropdownMenuAnchorType.PrimaryNotEditable)
                .fillMaxWidth()
                .height(48.dp)
                .background(colors.backgroundTextField, shape)
                .border(1.dp, if (expanded) colors.primary else colors.light, shape)
                .padding(horizontal = 16.dp),
            verticalAlignment = Alignment.CenterVertically
        ) {
            Text(
                text = selected.ifEmpty { placeholder },
                color = if (selected.isEmpty()) colors.text.copy(alpha = 0.5f) else colors.text,
                modifier = Modifier.weight(1f)
            )
            Icon(
                imageVector = Icons.Default.KeyboardArrowDown,
                contentDescription = null,
                tint = colors.primary,
                modifier = Modifier.rotate(arrowRotation)
            )
        }

        // 2. The list
        ExposedDropdownMenu(
            expanded = expanded,
            onDismissRequest = { expanded = false }, // tap outside to close
            containerColor = colors.backgroundCard,
            shape = RoundedCornerShape(16.dp)
        ) {
            options.forEach { option ->
                DropdownMenuItem(
                    text = {
                        Text(
                            text = option,
                            color = if (option == selected) colors.primary else colors.text
                        )
                    },
                    trailingIcon = {
                        if (option == selected) {
                            Icon(Icons.Default.Check, contentDescription = null, tint = colors.primary)
                        }
                    },
                    onClick = {
                        onSelectedChange(option) // save the choice
                        expanded = false          // close the list
                    }
                )
            }
        }
    }
}

Import nhớ chọn các dòng androidx.compose.... KeyboardArrowDown và Check có trong icons.core của project.
