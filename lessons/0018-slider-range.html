Slider: <input type="range"> và ion-range, kéo để chọn một giá trị

Bài 17: xong. Bạn làm đủ các kiểu dropdown: text, radio, checkbox chọn nhiều, ảnh + text, thêm cả lớp nền mờ (scrim) có lỗ khoét đúng chỗ ô dropdown. AppDropdown và AppCheckboxDropdown dùng được ở mọi trang.

Bài này là thanh kéo Slider, thành phần form cuối của Nhóm 2. Phần carousel (vuốt qua lại giữa các ảnh hoặc thẻ text) nằm ở Bài 18b. Bài chia 2 phần giống bài 16, 17: Phần A viết thẳng trong trang để hiểu từng dạng, Phần B gom lại thành AppSlider.

Kết quả mong đợi

Trang Slider (mở từ side menu) có 4 thanh kéo, đi từ dễ đến khó: kéo một giá trị, có nấc, hai đầu kéo (khoảng giá), và có icon ở hai đầu. Mỗi thanh có tên bên trái và giá trị bên phải, giá trị đổi ngay khi kéo. Hình kéo được.

Chú ý khi so sánh: đây là kiểu Slider mới của Material3 1.4 (bản project đang dùng). Nút kéo là một vạch dọc, không phải hình tròn. Thanh dày, phần đã kéo màu colors.primary, phần còn lại màu colors.light, hai bên nút kéo có khe hở nhỏ. Cuối thanh có một chấm nhỏ ("stop"). Thanh Fuel level chỉ dừng ở 5 điểm và có chấm ở mỗi nấc. Thanh Price có hai nút kéo, đoạn giữa hai nút mới tô màu. Ở Dark Mode, colors.light rất tối nên phần chưa kéo khó thấy, điều đó là bình thường.

1. So với web và Ionic

HTML / Ionic 
<input type="range"
  min="0" max="100" step="25"
  value="50">

<ion-range [(ngModel)]="price"
  [dualKnobs]="true"
  [ticks]="true" [snaps]="true">
  <ion-icon slot="start" ...>
  <ion-icon slot="end" ...>
</ion-range>
Compose 
Slider(
    value = fuel,                // giá trị hiện tại
    onValueChange = { fuel = it },
    valueRange = 0f..100f,       // min..max
    steps = 3                    // số nấc ở giữa
)

RangeSlider(                     // dualKnobs
    value = price,               // 100f..500f
    onValueChange = { price = it },
    valueRange = 0f..1000f
)
// icon 2 đầu: tự đặt trong Row

Giống AppSwitch ở Bài 12: Slider không tự nhớ giá trị. Trang giữ State, truyền vào value, và cập nhật State trong onValueChange. Đây vẫn là state hoisting.

2. Ba điều mới

a) Số thực Float: 60f

Slider dùng số có phần thập phân (Float), vì khi kéo tay giá trị có thể là 60.37. Viết số Float thì thêm chữ f: 60f, 0f..100f. Muốn hiện số tròn thì dùng brightness.roundToInt() (60.37 → 60, 60.6 → 61), giống Math.round() trong JS. Cần import kotlin.math.roundToInt.

Để giữ State kiểu Float, dùng mutableFloatStateOf(60f) thay cho mutableStateOf(60f). Cả hai đều chạy, nhưng Android Studio sẽ gạch vàng gợi ý dùng bản Float vì nó nhẹ hơn.

b) steps = số nấc ở giữa, không tính hai đầu

Muốn dừng ởSố điểm dừngsteps
0, 25, 50, 75, 10053
0, 100, 200, ... 1000119
1, 2, 3, 4, 5 (chấm sao)53

Công thức: steps = số điểm dừng − 2. Khác với web: step="25" trên web là khoảng cách giữa các nấc, còn steps trong Compose là số lượng nấc ở giữa.

c) RangeSlider: giá trị là một khoảng

var price by remember { mutableStateOf(100f..500f) } // a range: from 100 to 500
price.start        // 100f, left handle
price.endInclusive // 500f, right handle

100f..500f chính là kiểu bạn đã dùng cho valueRange. Ở đây nó là giá trị đang chọn.

3. Phần A: viết thẳng trong trang

A1. Tạo trang SliderPage.kt, route "slider". Khung trang giống DropdownPage: AppDrawer → AppPage → AppTopBar("Slider") có nút menu. Không cần bottomBar. Sau đó thêm 2 chỗ:

  • MainActivity.kt: composable(route = "slider") { SliderPage(...) }
  • AppDrawer.kt: thêm MenuItem("Slider", "slider", Icons.Default.Settings) vào danh sách menu

A2. Brightness: kéo một giá trị. Đặt trong content của AppPage:

var brightness by remember { mutableFloatStateOf(60f) }

val sliderColors = SliderDefaults.colors(
    thumbColor = colors.primary,         // the vertical handle
    activeTrackColor = colors.primary,   // dragged part
    inactiveTrackColor = colors.light,   // remaining part
    activeTickColor = colors.white,      // step dots on the dragged part
    inactiveTickColor = colors.primary,  // step dots on the remaining part
)

Row(modifier = Modifier.fillMaxWidth()) {
    Text(text = "Brightness", modifier = Modifier.weight(1f))
    Text(text = "${brightness.roundToInt()}%", color = colors.primary)
}
Slider(
    value = brightness,
    onValueChange = { brightness = it }, // it = new value while dragging
    valueRange = 0f..100f,
    colors = sliderColors
)

Row + weight(1f) đẩy giá trị sang phải, giống justify-content: space-between. sliderColors khai báo một lần để 4 thanh dùng chung.

A3. Fuel level: có nấc. Tự viết như A2, giá trị đầu 50f, thêm steps = 3. Kéo thử: thanh chỉ dừng ở 0, 25, 50, 75, 100.

A4. Price: hai đầu kéo.

var price by remember { mutableStateOf(100f..500f) }

Row(modifier = Modifier.fillMaxWidth()) {
    Text(text = "Price", modifier = Modifier.weight(1f))
    Text(
        text = "${price.start.roundToInt()}k – ${price.endInclusive.roundToInt()}k",
        color = colors.primary
    )
}
RangeSlider(
    value = price,
    onValueChange = { price = it },
    valueRange = 0f..1000f,
    steps = 9,            // stops every 100: 0, 100, ... 1000
    colors = sliderColors
)

A5. Ringtone: icon ở hai đầu. Project không có icon loa trong icons.core, nên dùng Icons.Default.Notifications (cái chuông): bên trái chuông nhỏ 16dp, bên phải chuông to 24dp.

var ringtone by remember { mutableFloatStateOf(30f) }

Row(verticalAlignment = Alignment.CenterVertically) {
    Icon(Icons.Default.Notifications, contentDescription = null,
        tint = colors.primary, modifier = Modifier.size(16.dp))
    Slider(
        value = ringtone,
        onValueChange = { ringtone = it },
        valueRange = 0f..100f,
        colors = sliderColors,
        modifier = Modifier.weight(1f).padding(horizontal = 8.dp) // take the space between the icons
    )
    Icon(Icons.Default.Notifications, contentDescription = null,
        tint = colors.primary, modifier = Modifier.size(24.dp))
}

Lưu ý: nếu không ghi valueRange thì mặc định là 0f..1f (giá trị từ 0 đến 1). Dòng tên + giá trị "Ringtone 30" bạn tự viết.

Quan sát trước khi sang Phần B: dòng "tên + giá trị" lặp lại 4 lần, mỗi trang mới lại phải khai báo sliderColors. Phần B gom phần lặp vào một component.

4. Phần B: component AppSlider

Bước 1: tạo ui/components/slider/AppSlider.kt. Code mẫu (đã build thử trên project, chạy được):

@Composable
fun AppSlider(
    label: String,                                   // name on the left
    value: Float,                                    // current value, kept by the page
    onValueChange: (Float) -> Unit,                  // tell the page the new value
    modifier: Modifier = Modifier,
    valueRange: ClosedFloatingPointRange<Float> = 0f..100f,
    steps: Int = 0,                                  // 0 = no steps
    valueText: (Float) -> String = { "${it.roundToInt()}" }, // how to show the value
    leadingIcon: @Composable (() -> Unit)? = null,   // optional icon on the left
    trailingIcon: @Composable (() -> Unit)? = null,  // optional icon on the right
) {
    val hasIcon = leadingIcon != null || trailingIcon != null

    Column(modifier = modifier.fillMaxWidth()) {
        // 1. Label + value
        Row(modifier = Modifier.fillMaxWidth()) {
            Text(
                text = label,
                color = colors.text,
                fontWeight = FontWeight.SemiBold,
                modifier = Modifier.weight(1f)
            )
            Text(text = valueText(value), color = colors.primary, fontWeight = FontWeight.SemiBold)
        }
        // 2. Icon + slider + icon
        Row(verticalAlignment = Alignment.CenterVertically) {
            if (leadingIcon != null) leadingIcon()
            Slider(
                value = value,
                onValueChange = onValueChange,
                valueRange = valueRange,
                steps = steps,
                colors = SliderDefaults.colors(
                    thumbColor = colors.primary,
                    activeTrackColor = colors.primary,
                    inactiveTrackColor = colors.light,
                    activeTickColor = colors.white,
                    inactiveTickColor = colors.primary,
                ),
                modifier = Modifier
                    .weight(1f)
                    .padding(horizontal = if (hasIcon) 8.dp else 0.dp)
            )
            if (trailingIcon != null) trailingIcon()
        }
    }
}

Hai kiểu tham số mới

  • valueText: (Float) -> String: tham số là một hàm, nhận số và trả về chữ. Giống truyền (v) => v + '%' trong JS. Trang tự quyết định cách hiện: "60%", "60 km"... Mặc định chỉ hiện số tròn.
  • leadingIcon: @Composable (() -> Unit)? = null: slot có thể không có (dấu ?), giống onClick nullable của AppRadio. Có thì vẽ, không có thì bỏ qua: if (leadingIcon != null) leadingIcon().

Bước 2: thay Phần A trong SliderPage bằng AppSlider. Ví dụ:

AppSlider(
    label = "Fuel level",
    value = fuel,
    onValueChange = { fuel = it },
    steps = 3,
    valueText = { "${it.roundToInt()}%" }
)

AppSlider(
    label = "Ringtone",
    value = ringtone,
    onValueChange = { ringtone = it },
    leadingIcon = {
        Icon(Icons.Default.Notifications, contentDescription = null,
            tint = colors.primary, modifier = Modifier.size(16.dp))
    },
    trailingIcon = {
        Icon(Icons.Default.Notifications, contentDescription = null,
            tint = colors.primary, modifier = Modifier.size(24.dp))
    }
)

Brightness bạn tự đổi. Giữa các AppSlider thêm khoảng cách bằng Arrangement.spacedBy hoặc Spacer, vì component không tự có khoảng cách bên ngoài (quy tắc của bạn từ các bài trước).

Bước 3: tự làm AppRangeSlider trong cùng thư mục slider/. Gợi ý: chép AppSlider, đổi:

  • value: ClosedFloatingPointRange<Float> và onValueChange: (ClosedFloatingPointRange<Float>) -> Unit
  • valueText nhận ClosedFloatingPointRange<Float>, mặc định { "${it.start.roundToInt()} – ${it.endInclusive.roundToInt()}" }
  • Slider → RangeSlider; bỏ icon cho gọn

Dùng cho Price: valueText = { "${it.start.roundToInt()}k – ${it.endInclusive.roundToInt()}k" }.

Bước 4: kiểm tra. Kéo cả 4 thanh, giá trị bên phải đổi ngay. Fuel level chỉ dừng ở 5 điểm. Hai nút của Price không vượt qua nhau. Kiểm tra Light/Dark.

Thử thách (tuỳ chọn):

  • Thêm enabled: Boolean = true vào AppSlider và truyền xuống Slider. Gắn một AppSwitch "Auto brightness": bật thì thanh Brightness bị khoá.
  • Slider còn có onValueChangeFinished = { ... }: chỉ chạy một lần khi thả tay, hợp để lưu hoặc gửi dữ liệu (giống sự kiện change so với input trên web). Thử hiện một dòng Text("Saved: 60") chỉ cập nhật khi thả tay.
